# MLE = SSE — 우리 1D 예제로 끝까지 따라가기

> "**노이즈가 가우시안이면 MLE = SSE 최소화**" 라는 추상 문장을,
> 우리가 쓰던 1D 모델로 **숫자까지 직접 계산** 해서 확인.
>
> 책처럼 한 줄씩 따라오기.

---

## 📋 MLE 풀이 — 7단계 표준 흐름

**1. 모델 정의** — 예: $\hat{y}(t; w) = e^{-wt}$

**2. PDF (확률 가정)** — 가우시안 노이즈:

$$y_i \sim \mathcal{N}(\hat{y}_i, \sigma^2)$$

**3. Likelihood (모든 점 곱)**:

$$L(w) = \prod_i P(y_i \mid w)$$

**4. log 적용 — 곱이 합으로**:

$$\ell(w) = \log L(w) = \sum_i \log P(y_i \mid w)$$

**5. SSE 등장 (가우시안 케이스)**:

$$\ell(w) = C - \frac{\text{SSE}(w)}{2\sigma^2}$$

**6. 최적화** — GN / LM / Newton / Dogleg 으로 SSE 최소화

**7. 다리 등식 — MLE 최대 = SSE 최소** ★

$$\arg\max_w \ell(w) = \arg\min_w \text{SSE}(w)$$

| 단계 | 영역 | 도구 |
|---|---|---|
| 1 | 모델 함수 | $\hat{y} = f(t; w)$ |
| 2 | **확률 가정** | 가우시안 / 베르누이 / ... |
| 3 | likelihood 정의 | $\prod$ |
| 4 | 다루기 쉬운 형태 | $\log$ |
| 5 | **손실 함수 도출** | $\sum r^2$ (가우시안) |
| 6 | 알고리즘 | GN / LM / Newton / Dogleg |
| 7 | **다리 등식** | $\arg\max \ell = \arg\min \text{SSE}$ |

> **이 7단계는 어떤 문제든 적용 가능** — 회귀, 분류, IK, SLAM 등.
>
> 아래 본문은 가우시안 회귀 케이스로 단계별 숫자 검증.

---

## 1. 출발점 — 모델과 데이터

### 모델

$$\hat{y}(t; w) = e^{-wt}$$

파라미터 $w$ 1개. 진짜 값 $w^* = 0.5$.

### 데이터 (5개점, 노이즈 포함)

| $t_i$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| $y_i$ | 1.05 | 0.55 | 0.41 | 0.22 | 0.19 |

이 5개점이 진짜 곡선 $e^{-0.5 t}$ 주변에 흩어져 있음 — 그 흩어짐이 **노이즈**.

---

## 2. 노이즈 가정 — 가우시안

> **"진짜 모델 + 가우시안 노이즈"**

각 점:

$$y_i = \underbrace{e^{-w t_i}}_{\text{진짜 값 } \hat{y}_i} + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)$$

- 노이즈 평균 0 (편향 없음)
- 노이즈 분산 $\sigma^2$ (모든 점 동일)
- **각 노이즈 독립**

같은 말로 다시 쓰면, **$y_i$ 자체가 가우시안 분포**:

$$y_i \sim \mathcal{N}(\hat{y}_i, \sigma^2)$$

→ "$y_i$ 는 평균 $\hat{y}_i$, 분산 $\sigma^2$ 인 종 모양에서 뽑힌 값".

### 시각적

```
 yᵢ                                                
   │                                               
   │     ●  ← 관측 yᵢ                              
   │   ╱│                                          
   │  ╱ │                                          
   │ ──●  ← 모델 ŷᵢ = e^(-w·tᵢ)                    
   │   ╲                                            
   │    ╲▒  가우시안 N(ŷᵢ, σ²)                    
   │     ▒▒▒                                        
   └────────→ tᵢ                                   
```

---

## 3. 한 점의 확률 (PDF)

가우시안 PDF 식 — 각 기호 라벨:

$$P(y_i \mid w) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(\overbrace{y_i}^{\text{관측}} - \overbrace{\hat{y}_i}^{\text{모델=평균 }\mu})^2}{2\sigma^2}\right)$$

| 기호 | 정체 | 역할 |
|---|---|---|
| $\hat{y}_i = e^{-w t_i}$ | **모델 예측값 (=평균 $\mu$)** | 가우시안 종의 **중심** |
| $\sigma^2$ | **분산** | 종의 **퍼짐 정도** |
| $y_i$ | **관측값** (실제 측정한 데이터) | "**그 자리에 떨어진 점**" |
| $r_i = y_i - \hat{y}_i$ | **잔차** | 종 중심에서 얼마나 벗어났나 |

```
종 모양 (가우시안):                                
                                                  
        ╭─────╮  ← 정점 = ŷᵢ (모델 예측 = 평균)   
       ╱       ╲                                  
      ╱    ●    ╲   ← yᵢ (실제 관측값)            
     ╱     │     ╲                                
   ────────┼────────                              
           │                                       
   yᵢ - ŷᵢ = rᵢ (잔차)                           
```

→ **지수 안에 (잔차)² 가 이미 들어있음**. 모든 핵심의 출발.

---

## 4. 5개 점 모두의 likelihood — 곱

각 점 독립이라 likelihood = 곱:

$$L(w) = \prod_{i=1}^{5} P(y_i \mid w)$$

대입:

$$L(w) = \prod_{i=1}^{5} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{r_i^2}{2\sigma^2}\right)$$

상수 5개 곱 + 지수 5개 곱 (지수의 곱 = 지수 안 합):

$$\boxed{L(w) = \left(\frac{1}{\sqrt{2\pi\sigma^2}}\right)^{\!5} \cdot \exp\!\left(-\frac{1}{2\sigma^2}\sum_{i=1}^{5} r_i^2\right)}$$

→ 지수 안 합이 곧 **SSE($w$)**.

#### 📘 참고 — 왜 곱이 합으로 바뀌나

지수함수의 성질:

$$e^a \cdot e^b = e^{a+b}$$

여러 항으로 일반화:

$$\prod_i e^{a_i} = e^{\sum_i a_i}$$

→ **지수의 곱은 지수 안 합으로 변환**.

우리 식에 적용 ($a_i = -r_i^2/2\sigma^2$):

$$\prod_i \exp\!\left(-\frac{r_i^2}{2\sigma^2}\right) = \exp\!\left(-\sum_i \frac{r_i^2}{2\sigma^2}\right) = \exp\!\left(-\frac{1}{2\sigma^2}\sum_i r_i^2\right)$$

(공통 분모 $1/(2\sigma^2)$ 만 밖으로 묶음.)

→ **곱 5개 → 지수 1개 + 안에 합** = SSE 가 자연스럽게 등장하는 비밀.

---

## 5. 숫자로 — $w = 0.5$, $\sigma = 0.05$ 가정

### 잔차 표

| $t_i$ | $y_i$ | $\hat{y}_i = e^{-0.5 t_i}$ | $r_i = y_i - \hat{y}_i$ | $r_i^2$ |
|---|---|---|---|---|
| 0 | 1.05 | 1.000 | 0.050 | 0.0025 |
| 1 | 0.55 | 0.607 | -0.057 | 0.0032 |
| 2 | 0.41 | 0.368 | 0.042 | 0.0018 |
| 3 | 0.22 | 0.223 | -0.003 | 0.00001 |
| 4 | 0.19 | 0.135 | 0.055 | 0.0030 |

$$\text{SSE}(0.5) = \sum r_i^2 = 0.0105$$

### 지수 부분

$$-\frac{0.0105}{2 \cdot 0.05^2} = -\frac{0.0105}{0.005} = -2.1$$

$$\exp(-2.1) \approx 0.1225$$

### 상수 부분

$$\left(\frac{1}{\sqrt{2\pi \cdot 0.0025}}\right)^{5} = \left(\frac{1}{\sqrt{0.0157}}\right)^{5} \approx (7.98)^5 \approx 32{,}300$$

### 합치면

$$L(0.5) \approx 32{,}300 \cdot 0.1225 \approx 3{,}956$$

(상수가 큰 이유: $\sigma$ 작아서 PDF 정점이 매우 높음.)

---

## 6. 여러 $w$ 에서 비교 — likelihood 곡선

| $w$ | SSE($w$) | $-\text{SSE}/(2\sigma^2)$ | $L(w)$ (대략) |
|---|---|---|---|
| 0.0 | 1.97 | $-394$ | $\approx 0$ |
| 0.3 | 0.21 | $-42$ | $\approx 0$ |
| **0.5** | **0.0105** | **−2.1** | **3{,}956** ★ |
| 0.7 | 0.13 | $-26$ | $\approx 10^{-7}$ |
| 1.5 | 0.30 | $-60$ | $\approx 10^{-22}$ |

→ **$w = 0.5$ 에서 압도적 정점**. 다른 곳은 거의 0.

가우시안 PDF 의 지수 함수 때문에 likelihood 가 **매우 뾰족** — 작은 SSE 차이가 거대한 $L$ 차이를 만듦. 그래서 컴퓨터로 다루기 힘들어 → log 가 등장.

---

## 7. log 취하기 — 합리적 척도로

$$\ell(w) = \log L(w)$$

위의 $L(w)$ 식에 log 적용:

### Step 1. log 가 곱을 합으로

$$\ell(w) = \log\!\left[\left(\frac{1}{\sqrt{2\pi\sigma^2}}\right)^{\!5}\right] + \log\!\left[\exp\!\left(-\frac{\text{SSE}}{2\sigma^2}\right)\right]$$

### Step 2. 각 항 정리

$$= 5 \log\!\frac{1}{\sqrt{2\pi\sigma^2}} - \frac{\text{SSE}(w)}{2\sigma^2}$$

(둘째 항: $\log e^x = x$.)

### Step 3. 첫 항은 $w$ 무관 — 상수로 묶기

$$\boxed{\ell(w) = C - \frac{\text{SSE}(w)}{2\sigma^2}, \qquad C = 5 \log\!\frac{1}{\sqrt{2\pi\sigma^2}}}$$

★ **핵심 식** ★

→ "**log-likelihood = 상수 − SSE 의 양의 배수**".

---

## 8. 숫자로 — $\ell$ 직접 계산

$\sigma = 0.05$ 일 때 $C = 5 \log(1/\sqrt{2\pi \cdot 0.0025}) \approx 5 \cdot 2.077 = 10.39$.

| $w$ | SSE | $-\text{SSE}/(2\sigma^2)$ | $\ell(w) = C + \cdot$ |
|---|---|---|---|
| 0.0 | 1.97 | $-394$ | $-383.6$ |
| 0.3 | 0.21 | $-42$ | $-31.6$ |
| **0.5** | **0.0105** | **−2.1** | **8.29** ★ |
| 0.7 | 0.13 | $-26$ | $-15.6$ |
| 1.5 | 0.30 | $-60$ | $-49.6$ |

→ $\ell$ **최댓값 = $w = 0.5$**.

## 10. 왜 $\sigma$ 가 결과에 영향 없나

$$\arg\max_w \ell(w) = \arg\max_w \left[C - \frac{\text{SSE}(w)}{2\sigma^2}\right]$$

분석:
- $C$ 는 $w$ 무관 → 위치에 영향 없음
- $\dfrac{1}{2\sigma^2}$ 는 **양의 상수** → SSE 곡선 모양 그대로, 스케일만 바뀜
- 양의 상수 곱한 함수의 최솟값 위치는 불변

$$\Rightarrow \;\;\arg\max_w \ell(w) = \arg\min_w \text{SSE}(w)$$

★ **MLE 답 = SSE 최소화 답**

→ $\sigma$ 모르더라도 SSE 최소화는 같은 답을 줌.

### 보이는 것

| 캔버스 | 의미 |
|---|---|
| 위: $(t, y)$ | 데이터 + 현재 모델 + 각 점에 가우시안 종 |
| 가운데: SSE($w$) | 최소화 대상 (블루) |

### 실험

1. 슬라이더 0.5 근처 → SSE 최저 ↔ ℓ 최고
2. $\sigma$ 슬라이더 키움 → ℓ 곡선 평평해짐, SSE 곡선 그대로 (스케일만 변화)
3. 그래도 **최댓값 위치는 동일** → MLE 답 변하지 않음 ✓

별다른 선언 없이 우리는 60년 표준 통계 추정을 하고 있었던 것.

## 13. 만약 노이즈가 가우시안이 아니라면?

같은 데이터에 다른 노이즈 가정 적용:

| 노이즈 | 한 점 likelihood | 합 후 손실 |
|---|---|---|
| **가우시안** | $\propto e^{-r^2/2\sigma^2}$ | **SSE** ($\sum r^2$) |
| **라플라스** | $\propto e^{-\|r\|/b}$ | **LAD** ($\sum \|r\|$) |
| **Huber** | 가우시안+라플라스 혼합 | **Huber loss** |

→ 노이즈 가정이 손실 함수를 결정.

### 예: 우리 데이터에 outlier 추가

만약 $y_3$ 이 노이즈가 아니라 잘못된 측정으로 $y_3 = 5.0$ (원래 0.22) 이었다면:
- **SSE**: outlier 한 점이 잔차 제곱 $\approx 24$ 기여 → 모든 다른 점 무시되고 outlier 따라감 → **추정 망가짐**
- **LAD**: 잔차 절댓값 $\approx 4.8$ 기여 → 영향 적음 → **추정 robust**

이게 **"노이즈 가정에 따라 손실 선택" 의 실용적 의미**.
