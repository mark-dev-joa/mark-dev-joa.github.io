Part 2·1 최대우도추정(MLE) — 동전과 가우시안

Created on April 27, 2026 by mark

2026   ·   mle   likelihood   gaussian   sse   cross-entropy   statistics   ·   math   optimization

MLE — 우리가 풀던 SSE 의 진짜 정체

“노이즈가 가우시안이라고 가정하면 MLE = SSE 최소화”

지금까지 그냥 “잔차 제곱합 최소화” 했지만, 그게 확률론적으로 정당화되는 이유 가 MLE.

0. 왜 MLE 인가

지금까지 비선형 피팅에서 의문 들었던 것들:

  • 왜 잔차의 제곱? 절댓값이나 4제곱은 안 되나?
  • 왜 모든 데이터에 같은 가중치?
  • 노이즈가 데이터마다 다르면?
  • 데이터 신뢰도 다르면?

→ MLE 가 모두 답해줌.

이 문서에서는 두 단계로 진행:

Stage 내용
1 동전 던지기 — likelihood 가 뭔지 직관 잡기
2 가우시안 노이즈 → MLE → SSE 자연 등장

Stage 1 — 동전 던지기로 MLE 직관 잡기

1. 확률 vs Likelihood — 같은 식, 다른 관점

같은 식이지만 무엇을 변수로 보느냐 가 다름.

확률 (Probability)

파라미터 고정 → 데이터의 확률

“동전이 공정하다 ($\theta = 0.5$). 5번 던져 HHTHT 가 나올 확률은?”

Likelihood (가능도)

데이터 고정 → 파라미터의 그럴듯함

“HHTHT 를 봤다. 동전의 $\theta$ 가 얼마일 때 이 데이터가 가장 그럴듯한가?”

표

  확률 $P(D \mid \theta)$ Likelihood $L(\theta \mid D)$
변수 데이터 $D$ 파라미터 $\theta$
고정 파라미터 $\theta$ 데이터 $D$
합 모든 $D$ 합 = 1 합 ≠ 1 (확률분포 아님)
질문 “이 파라미터일 때 이 데이터가 나올 가능성?” “이 데이터를 본 후, 어떤 파라미터가 가장 그럴듯?”

→ 수식은 똑같지만 관점이 정반대.

2. 동전 던지기 — 가장 간단한 MLE

모델

  • 동전 한 번 던져 앞이 나올 확률: $\theta$ (파라미터 1개)
  • 뒤가 나올 확률: $1 - \theta$
  • 각 던짐은 독립

데이터

5번 던졌더니: HHTHT (앞 3, 뒤 2)

Likelihood 식 세우기

각 던짐의 확률 (독립이므로 곱):

\[L(\theta) = P(H) \cdot P(H) \cdot P(T) \cdot P(H) \cdot P(T)\] \[= \theta \cdot \theta \cdot (1-\theta) \cdot \theta \cdot (1-\theta)\] \[\boxed{L(\theta) = \theta^3 (1-\theta)^2}\]

→ $\theta$ 의 함수 = 1D 곡선 (최적화 대상!)

어떻게 푸는가 — 미분 = 0

“어디서 가장 큰가?” → 미분해서 0인 지점.

Step 1. log 취하기 (다음 섹션에서 왜인지 설명)

\[\ell(\theta) = \log L(\theta) = 3 \log \theta + 2 \log(1-\theta)\]

Step 2. 미분

\[\frac{d\ell}{d\theta} = \frac{3}{\theta} - \frac{2}{1-\theta}\]
log 미분 규칙 (보충)

위 미분에 사용된 공식 두 가지:

규칙 1: 자연로그의 미분

\[\frac{d}{dx}\log x = \frac{1}{x}\]

규칙 2: 연쇄법칙으로 합성된 log

\[\frac{d}{dx}\log f(x) = \frac{f'(x)}{f(x)}\]

(증명: $u = f(x)$ 두고 $\dfrac{d \log u}{dx} = \dfrac{d \log u}{du} \cdot \dfrac{du}{dx} = \dfrac{1}{u} \cdot f’(x)$.)

우리 식에 적용:

항 미분 사용 규칙
$3 \log \theta$ $\dfrac{3}{\theta}$ 규칙 1 (× 상수 3)
$2 \log(1-\theta)$ $\dfrac{2 \cdot (-1)}{1-\theta} = -\dfrac{2}{1-\theta}$ 규칙 2: $f = 1-\theta, f’ = -1$

합쳐서:

\[\frac{d\ell}{d\theta} = \frac{3}{\theta} + \left(-\frac{2}{1-\theta}\right) = \frac{3}{\theta} - \frac{2}{1-\theta}\]

Step 3. = 0

\[\frac{3}{\theta} = \frac{2}{1-\theta}\] \[3(1-\theta) = 2\theta\] \[3 - 3\theta = 2\theta \;\;\Rightarrow\;\; 5\theta = 3\] \[\boxed{\theta_{\text{MLE}} = \frac{3}{5} = 0.6}\]

직관과 일치 ★

앞이 5번 중 3번 나왔으니, 가장 그럴듯한 $\theta$ 는 관찰 빈도 = 3/5.

이게 MLE 의 자연스러움 — 우리 직관이 수학적으로 정당화됨.

일반화

$N$ 번 중 앞 $k$ 번:

\[L(\theta) = \theta^k (1-\theta)^{N-k}\] \[\boxed{\theta_{\text{MLE}} = \frac{k}{N}}\]

3. log-likelihood — 왜 항상 log 를 취하나

이유 1. 곱 → 합

데이터 $N$ 개의 likelihood:

\[L(\theta) = \prod_{i=1}^{N} P(x_i \mid \theta)\]

log 취하면:

\[\ell(\theta) = \sum_{i=1}^{N} \log P(x_i \mid \theta)\]

→ 곱 → 합, 합이 미분 훨씬 쉬움.

이유 2. 수치 안정성

$N$ 이 크면:

  • $L = 0.01 \times 0.02 \times \cdots = 10^{-200}$ → 언더플로우
  • $\ell = \log(0.01) + \log(0.02) + \cdots = -460$ → 안전

이유 3. 같은 최댓값

$\log$ 는 단조증가 함수 → $L$ 의 최댓값 위치 = $\ell$ 의 최댓값 위치.

→ 어느 걸 최대화하든 같은 답.

시각적

L(θ):  곡선 (작은 값들의 곱, 매우 뾰족)

       ╱  ╲
      ╱    ╲
   ──╱──────╲──── θ
      ↑
      최대

      같은 위치

4. 인터랙티브 데모 — 동전 MLE

보이는 것

색상 의미
🔵 위 곡선 $L(\theta) = \theta^k (1-\theta)^{N-k}$
🟣 아래 곡선 $\ell(\theta) = k \log\theta + (N-k)\log(1-\theta)$
🔴 빨간 점/선 현재 슬라이더의 $\theta$
⭐ 파란 별 MLE 답 $\theta^* = k/N$

조작

  • θ 슬라이더: 후보 파라미터 움직이기 (likelihood 값 확인)
  • 앞면 수 / 뒷면 수: 데이터 바꾸기
  • 데이터가 많아질수록 곡선이 뾰족해지는 것 확인 (= 확신 증가)

실험

  1. 앞 3, 뒤 2 → MLE = 0.6
  2. 앞 30, 뒤 20 → MLE = 0.6 (같지만 곡선 훨씬 뾰족!)
  3. 앞 1, 뒤 0 → MLE = 1.0 (극단, 데이터 너무 적음)

5. MLE 의 일반 절차

“likelihood 식 세우기 → log → 미분 → = 0 → 풀기”

Step 동전 예
1. 데이터 HHTHT
2. 모델 $P(H) = \theta$
3. Likelihood $L = \theta^3 (1-\theta)^2$
4. log $\ell = 3\log\theta + 2\log(1-\theta)$
5. 미분 = 0 $3/\theta - 2/(1-\theta) = 0$
6. 풀기 $\theta^* = 3/5$

→ 이 패턴이 모든 MLE 에 동일.

다음 stage 에서 이 패턴을 연속 데이터 + 가우시안 노이즈 에 적용하면, 짜잔 — SSE 가 자연스럽게 등장.

Stage 2 — 가우시안 노이즈 → MLE → SSE 등장

🎯 이 Stage 의 한 줄 결론

\[\ell(w) = C - \frac{\text{SSE}(w)}{2\sigma^2}\]

이 한 등식이 확률의 세계 (likelihood) 와 최적화의 세계 (SSE) 를 잇는 다리.

$\ell$ 시점 $\text{SSE}$ 시점
“데이터가 그럴듯한 정도” “잔차 제곱합”
최대화 하고 싶음 최소화 하고 싶음
MLE GN/LM/Newton

이 다리 하나로 두 시점이 같은 답 을 줌. ★

아래 8개 섹션은 이 등식을 유도하고, 직관 잡고, 응용 하는 과정.

6. 회귀 문제의 확률 모델

문제 설정 (우리가 풀던 그 문제!)

데이터: $(t_i, y_i)$ for $i = 1, \dots, N$.

모델: $\hat{y}(t; w) = e^{-wt}$ (1D 비선형 피팅과 동일).

노이즈 가정

관측값 = 진짜 모델 + 가우시안 노이즈

\[y_i = \hat{y}(t_i; w) + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)\]
  • 노이즈 평균: 0 (편향 없음)
  • 노이즈 분산: $\sigma^2$ (모든 데이터 동일)
  • 각 노이즈 독립

다시 쓰면

$y_i$ 자체가 가우시안 분포를 따름:

\[y_i \sim \mathcal{N}\big(\hat{y}(t_i; w), \; \sigma^2\big)\]

→ 평균이 $\hat{y}(t_i; w)$ 인 종 모양.

시각적

★ 핵심 — 각 점마다 자기 가우시안 (오해 방지)

흔한 오해: “모든 데이터 점이 한 가우시안 분포에 같이 들어있다”.

실제로는 각 점마다 독립된 자기만의 가우시안:

→ 회귀 = “각 $t_i$ 위에 가우시안 종을 세우는 것”. → 종 중심들이 모델 곡선 따라가고, 데이터 점은 자기 종 안에서 흩어진 샘플.

그럼 “모델값 = 평균” 의 정확한 의미

$\hat{y}_i$ 자체는 결정적 (한 값) 이지만, $y_i$ 의 분포의 평균 으로 작동:

\[\mathbb{E}[y_i] = \mathbb{E}[\hat{y}_i + \epsilon_i] = \hat{y}_i + 0 = \hat{y}_i\]

(노이즈 평균 = 0 가정.)

→ “모델은 $y_i$ 의 조건부 평균을 예측”.

회귀 일반론:

\[\mathbb{E}[y \mid t] = f(t; w)\]

“$t$ 가 주어졌을 때 $y$ 의 평균은 $f(t; w)$”.

7. Likelihood 식 세우기

한 점의 확률 밀도

가우시안 PDF:

\[P(y_i \mid w) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}(t_i; w))^2}{2\sigma^2}\right)\]

보충 — PDF 값은 “확률” 이 아니라 “확률 밀도”

PDF 값이 $5.91$ 이라고 나오면:

  • ❌ “$y_i$ 가 일어날 확률 = 5.91” (확률은 1 이상 안 됨)
  • ✅ “$y_i$ 근처의 확률 밀도 = 5.91” (단위 $y$ 당 확률)
  확률 (이산) 확률 밀도 (연속)
한 점의 값 그 점의 확률 그 점 근처 밀도
단위 없음 (0~1) “단위당 확률” (1/$y$)
1 보다? ✗ 안 됨 ✓ 가능
진짜 확률 그 자체 PDF × 구간 폭 (적분)

→ PDF 값 자체는 “이 관측이 모델에 얼마나 잘 맞는지” 의 척도. 큰 값 = 잘 맞음.

전체 데이터 likelihood

각 점이 독립이므로 곱:

\[L(w) = \prod_{i=1}^{N} P(y_i \mid w) = \prod_{i=1}^{N} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)\]

(여기서 $\hat{y}_i = \hat{y}(t_i; w)$ 줄임 표기.)

→ $w$ 의 함수.

8. log 취하기 → SSE 등장 ★

Step 1. log 적용

\[\ell(w) = \log L(w) = \sum_{i=1}^{N} \log P(y_i \mid w)\]

Step 2. 한 점의 log

\[\log P(y_i \mid w) = \log\frac{1}{\sqrt{2\pi\sigma^2}} - \frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\] \[= \underbrace{-\frac{1}{2}\log(2\pi\sigma^2)}_{\text{상수, } w \text{ 무관}} - \frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\]

Step 3. 합치기

\[\ell(w) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2\]

→ 첫 항은 $w$ 무관 (상수), 두 번째 항만 $w$ 에 의존.

Step 4. 핵심 — SSE 등장!

먼저 SSE 정의 다시 쓰면:

\[\text{SSE}(w) = \sum_{i=1}^{N} (y_i - \hat{y}_i)^2\]

이걸 대입하면:

\[\boxed{\ell(w) = C - \frac{1}{2\sigma^2} \cdot \text{SSE}(w)}\]

(여기서 $C$ 는 $w$ 무관한 상수.)

Step 5. 최대화 = 최소화

$\ell(w) = C - \dfrac{\text{SSE}(w)}{2\sigma^2}$ 의 구조 분석:

식의 두 부분

부분 성격 $w$ 와 관계
$C$ 양수 상수 무관 (어떤 $w$ 든 같음)
$-\dfrac{\text{SSE}(w)}{2\sigma^2}$ 항상 음수 (SSE ≥ 0) $w$ 따라 변함

→ $\ell$ 의 변화는 두 번째 음수 항 에서만 옴.

논리 체인 — 한 단계씩

”$\ell(w)$ 를 최대화 하려면…”

  1. $\ell = C - \dfrac{\text{SSE}}{2\sigma^2}$ 에서 $C$ 는 고정
  2. $-\dfrac{\text{SSE}}{2\sigma^2}$ 음수 항 — 빼는 쪽
  3. 빼는 양 (SSE) 이 작을수록 ℓ 큼 ★
  4. → “빼는 양 작게” = “SSE 최소화”
  5. → $\arg\max_w \ell(w) = \arg\min_w \text{SSE}(w)$

숫자 직관

SSE $-\text{SSE}/(2 \cdot 0.05^2)$ $\ell$ ($C = 10$ 가정)
0.01 (작음) $-2$ $10 - 2 = 8$ ★ 최대
0.1 $-20$ $10 - 20 = -10$
1.0 (큼) $-200$ $10 - 200 = -190$

→ SSE 가 클수록 ℓ 가 더 음수쪽으로 끌려감. SSE = 0 일 때 ℓ 가장 큼.

부호의 흐름

   SSE(w)        −SSE(w)/(2σ²)        ℓ(w) = C + 위                
                                                                   
   작음 (좋음)  →  큼 (덜 음수)  →  ℓ 큼 ★ 정점 = MLE 답         
   큼 (나쁨)    →  작음 (더 음수)  →  ℓ 작음                       
                                                                   
   ↑                ↑                  ↑                            
   최소화 대상     최대화 대상         최대화 대상                  
                                                                   
        ☆ 세 가지가 모두 같은 w 에서 최적화됨 ☆

결론

\[\boxed{\arg\max_w \ell(w) \;=\; \arg\min_w \text{SSE}(w)}\]

→ MLE = SSE 최소화 ★

같은 일을 다른 시점으로 보는 것:

  • ℓ 시점: “최대화” — 양의 양 (likelihood) 키우기
  • SSE 시점: “최소화” — 음의 양 (잔차 제곱합) 줄이기

  • 모든 ML 손실 함수의 모범: “확률 가정 → 손실 도출” 의 첫 사례
  • IK, 번들조정, 카메라 캘리브레이션, 딥러닝 회귀… 의 공통 뿌리

Stage 1 의 동전이 이산 케이스, Stage 2 의 가우시안이 연속 케이스의 표준.

직관 — 왜 오차 커지면 확률 작아지나

가우시안 PDF 의 식 자체가 답:

\[P(y) \propto \exp\!\left(-\frac{r^2}{2\sigma^2}\right), \quad r = y - \hat{y}\]

지수 안에 $-r^2$ — 잔차 제곱에 마이너스. 잔차 커지면 빠르게 0으로 감쇠.

숫자로 ($\sigma = 1$ 일 때)

잔차 $r$ $r^2$ $\exp(-r^2/2)$ PDF 값
0 0 $1$ 1.00 (최대)
1 1 $0.61$ 0.61
2 4 $0.14$ 0.14
3 9 $0.011$ 0.01
5 25 $4 \times 10^{-6}$ 거의 0

→ 잔차 5σ 떨어지면 확률 밀도 거의 0. 잔차 커지면 폭발적 감쇠.

시각적

P(y)                                              
 ↑                                                
 │   ╭───╮  ← r=0 에서 최대                       
 │  ╱     ╲                                       
 │ ╱       ╲                                       
 │╱  큼     ╲ ← r=1 에서 60% 정도                
 │            ╲                                    
 │             ╲╲ ← r=2 에서 14%                  
 │               ╲╲╲                              
 │                  ───── ← r 커질수록 0으로     
 └──────────────────────  r                       
   0   1   2   3   4   5

모든 점 합치면 SSE 등장

각 점마다 $\log P(y_i) \propto -r_i^2$ → 모든 점 합:

\[\log L = \sum_i \log P_i \propto -\sum_i r_i^2 = -\text{SSE}\]

→ “SSE 커지면 log L 작아짐 → L 작아짐 (확률 작음)”.

두 시점 같은 일

  확률 시점 손실 시점
좋은 $w$ 모든 점 확률 큼 → $L$ 큼 모든 점 잔차 작음 → SSE 작음
나쁜 $w$ 모든 점 확률 작음 → $L$ 작음 모든 점 잔차 큼 → SSE 큼
목표 $L$ 최대화 SSE 최소화
답 같음 (가우시안 가정 하) ★  

시각으로

정답 w (잔차 작음):                                       
   ╭───╮                                                  
   ●●●●●  ← 모든 점이 종 정중앙 → 확률 큼               
                                                          
잘못된 w (잔차 큼):                                       
   ╭───╮                                                  
   ●     ●  ← 점들이 종 가장자리 → 확률 작음           
                                                          
        ↓ 모든 점 곱하기                                  
                                                          
정답 w  → ∏ 확률 큼 → likelihood 큼  ★                  
잘못 w  → ∏ 확률 작음 → likelihood 작음

→ “오차 커지면 확률 작아진다” 가 MLE = SSE 최소화 의 본질적 이유.

가우시안 식의 $-r^2$ 가 모든 것을 한 줄에 담고 있음.

9. 의문 해소

왜 “제곱” 인가?

가우시안 PDF 의 지수 안에 $(y - \mu)^2$ 가 있기 때문.

가우시안:

\[P \propto \exp\left(-\frac{(y - \mu)^2}{2\sigma^2}\right)\]

log 하면 자동으로 제곱 항.

→ “제곱” 은 임의 선택이 아니라 가우시안 가정의 직접적 결과.

왜 절댓값이나 4제곱은 안 되나?

손실 함수 어떤 노이즈 가정에 해당?    
제곱 $(y-\hat{y})^2$ 가우시안 $\mathcal{N}(0, \sigma^2)$    
절댓값 $ y-\hat{y} $ 라플라스 (양쪽 지수, outlier 강함)
Huber 가우시안 + 두꺼운 꼬리 (혼합)    
0/1 (분류) 베르누이    

→ 노이즈 모델이 손실 함수를 결정. SSE 를 쓰는 건 가우시안 가정을 한 것.

왜 모든 데이터에 같은 가중치?

→ 위 식에서 모든 데이터의 $\sigma$ 가 같다고 가정했기 때문.

만약 데이터마다 다른 $\sigma_i$ 를 가진다면:

\[\ell(w) = \text{const} - \frac{1}{2}\sum_i \frac{(y_i - \hat{y}_i)^2}{\sigma_i^2}\]

→ 가중 SSE (Weighted Least Squares):

\[\boxed{\text{WLS}(w) = \sum_i \frac{(y_i - \hat{y}_i)^2}{\sigma_i^2} = \sum_i w_i \cdot e_i^2, \quad w_i = 1/\sigma_i^2}\]

→ 노이즈 작은 데이터 (정밀한 데이터) 에 더 의존. 다음 stage 의 핵심.

10. 인터랙티브 데모 — 가우시안 MLE

보이는 것

색상 의미
🔵 데이터 점 노이즈 포함 관측값
🔴 현재 모델 슬라이더 $w$ 의 $\hat{y} = e^{-wt}$
🟢 데이터 점에 종 각 $\hat{y}_i$ 주변 가우시안 분포
🟣 아래 그래프 log-likelihood $\ell(w)$
🔵 (반전) $-\ell(w) \propto \text{SSE}(w)$

실험

  1. 슬라이더 움직이기 → 위 곡선 + 종 모양 따라옴
  2. 각 데이터 점이 종의 어디 위치하는지 관찰
  3. 종의 가운데 (모드) 에 데이터가 모일 때 ℓ 최대 = SSE 최소
  4. σ 슬라이더 → 종 폭 변화 → ℓ 곡선 모양 변화 (스케일은 변하나 위치는 동일)

→ “likelihood 최대 = 종이 데이터를 가장 잘 감싸는 위치” 직관.

11. 핵심 통찰 — MLE = SSE = 같은 일, 다른 시점

“최적화할 때 MLE 로 풀어도 되나?” → 사실 그게 우리가 한 일

시점 A: "SSE 를 최소화하자"            
                                       
   목적함수: SSE(w) = Σ rᵢ²            
   풀이: GN/LM/Dogleg                 
   답: w*                              
                                       
시점 B: "데이터를 가장 그럴듯하게"     
                                       
   목적함수: ℓ(w) = log L(w)          
   풀이: ∂ℓ/∂w = 0                    
   답: w_MLE                          
                                       
        ↓                              
                                       
   w* = w_MLE  ★ 정확히 같은 답

→ 이름만 다른 같은 최적화. SSE 최소화는 MLE 의 가우시안 케이스의 단축형.

MLE 시점에서 본 “회귀를 푸는 흐름”

1. 문제 설정 (회귀)                                
                                                   
2. MLE 로 정식화                                    
   "데이터 가장 그럴듯한 w 찾기"                    
                                                   
3. 가우시안 가정 → SSE 최소화로 변환              
   "잔차 제곱합 가장 작게"                         
                                                   
4. 비선형이라 직접 못 풂                           
                                                   
5. GN/LM/Dogleg/Newton 등 반복 알고리즘 등장 ★    
                                                   
6. 컴퓨터로 풀기 → w*

→ “MLE 로 푼다” = “GN/LM 으로 푼다” = 같은 일.

GN, LM, Newton 등은 MLE 를 풀기 위한 도구.

12. 위계 — 확률 가정에서 알고리즘까지

모든 ML / 통계 추정의 보편 구조.

   확률 모델 가정 (가우시안 / 라플라스 / 베르누이 / ...)
         ↓                                        
   MLE 정식화 (likelihood / log-likelihood)        
         ↓                                        
   손실 함수 도출 (SSE / LAD / cross-entropy / ...)
         ↓                                        
   알고리즘으로 풀기 (GN, LM, Newton, GD, Adam, ...)
         ↓                                        
   답 (파라미터 추정값)
노이즈 가정 MLE 풀이 결과 (손실 함수) 사용 분야
가우시안 $\mathcal{N}(0, \sigma^2)$ MSE / SSE 회귀, IK, 번들 조정
라플라스 MAE / LAD ($\sum |r|$) Robust regression
베르누이 Cross-entropy 이진 분류
카테고리 Softmax + CE 다중 분류
포아송 Poisson loss 카운트 데이터
Huber Huber loss outlier 강건

→ 모든 ML 손실 함수가 어떤 MLE 의 도출. 임의 선택 아님.

우리가 한 일 = 위계의 한 인스턴스

단계 우리 케이스
가정 가우시안 노이즈
MLE $L = \prod \mathcal{N}(y_i; \hat{y}_i, \sigma^2)$
손실 도출 SSE = $\sum (y_i - \hat{y}_i)^2$
알고리즘 GN, LM, Dogleg, Newton
답 $w^* \approx 0.5$

→ 위계의 모든 층 을 우리는 이미 거쳐옴.

이 시각이 왜 중요한가

새 문제 만나면:

  1. “노이즈는 어떤 분포?” 로 출발
  2. MLE 로 정식화
  3. 자동으로 손실 함수 도출
  4. 손실 형태 보고 적절한 알고리즘 선택
  5. 풀이

→ “어떤 손실을 써야 하지?” 막막할 필요 없음. 확률 가정에서 자동으로 흘러나옴.

13. MSE 와 Cross-entropy — 위계의 두 대표 인스턴스

우리가 배운 MLE 프레임의 가장 흔한 두 응용. 머신러닝 책에서 항상 등장: “회귀는 MSE, 분류는 cross-entropy”.

MSE — SSE 의 형제

\[\text{MSE} = \frac{1}{N}\sum_i (y_i - \hat{y}_i)^2 = \frac{\text{SSE}}{N}\]

→ “SSE 평균”. 점 개수로 나눈 것뿐.

  SSE MSE
정의 $\sum r_i^2$ $\sum r_i^2 / N$
데이터 늘면 자연히 커짐 일정 (스케일 무관)
arg min 답 같음 같음
사용처 통계학 (분산 추정) 머신러닝 (손실 비교)

→ “가우시안 노이즈 가정의 MLE 손실” = MSE = SSE/N (정규화된 형태).

딥러닝의 loss='mse' 는 정확히 이거.

Cross-entropy — 분류 문제의 SSE

분류 문제: $y \in {0, 1}$ (이진) 또는 $y \in {1, …, K}$ (다중).

이진 분류 — 베르누이 가정

모델 예측: $\hat{p}_i = P(y_i = 1)$ (예: 고양이일 확률).

각 점의 likelihood:

\[P(y_i \mid \hat{p}_i) = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\]

(Stage 1 의 동전 likelihood 와 같은 구조!)

log 취하고 음수 부호 → 손실:

\[\boxed{\text{CE} = -\sum_i \big[y_i \log \hat{p}_i + (1 - y_i) \log(1 - \hat{p}_i)\big]}\]

직관

$y_i$ (정답) $\hat{p}_i$ (예측) 손실 기여
1 0.99 (잘 맞음) $-\log 0.99 \approx 0.01$ ✓
1 0.01 (틀림) $-\log 0.01 \approx 4.6$ ✗
0 0.01 (잘 맞음) $-\log 0.99 \approx 0.01$ ✓
0 0.99 (틀림) $-\log 0.01 \approx 4.6$ ✗

→ “예측이 정답에 가까우면 0, 틀리면 큰 페널티” (log 의 무한 발산).

Stage 1 동전이 사실 cross-entropy

기억하시나요 — Stage 1 의 likelihood:

\[L = \theta^k (1-\theta)^{N-k}\]

log + 음수 + 점별 분해:

\[-\ell = -\sum_i \big[y_i \log\theta + (1-y_i)\log(1-\theta)\big]\]

(여기서 $y_i = 1$ 앞면, $y_i = 0$ 뒷면.)

★ 이게 cross-entropy 그 자체 ★

→ Stage 1 의 동전 MLE = “모든 점이 같은 $\theta$” 인 단순 cross-entropy 분류.

위계 표 — 모두 같은 패턴

문제 $y$ 값 분포 가정 likelihood MLE 손실
회귀 실수 가우시안 $\prod e^{-(y-\hat{y})^2/2\sigma^2}/\sqrt{…}$ MSE/SSE
이진 분류 0 또는 1 베르누이 $\prod \hat{p}^y(1-\hat{p})^{1-y}$ Cross-entropy
다중 분류 클래스 1~K 카테고리 $\prod \prod_c \hat{p}_c^{y_c}$ CE (소프트맥스)
카운트 자연수 포아송 $\prod e^{-\hat{\lambda}}\hat{\lambda}^y/y!$ Poisson loss

모두 같은 패턴: 분포 가정 → likelihood 곱 → log + 음수 → 손실.

흐름 비교 — MSE 와 CE 가 같은 뿌리

가우시안:                                          
   P(y|w) = e^(-r²/2σ²)/√...                       
        ↓ log + 음수 + 합                           
   MSE = Σ r²                                       
                                                    
베르누이:                                           
   P(y|w) = p^y · (1-p)^(1-y)                      
        ↓ log + 음수 + 합                           
   CE  = −Σ [y log p + (1-y) log(1-p)]             
                                                    
        ↓                                          
                                                    
   같은 MLE 패턴, 다른 분포만 대입

→ 둘 다 MLE 의 한 인스턴스.

그래서 ML 책의 그 문장

“회귀에는 MSE, 분류에는 cross-entropy 를 쓰세요”

의 정확한 의미:

“데이터의 노이즈/출력 분포 가정에 따라 MLE 가 자동 도출하는 손실. 회귀는 가우시안 → MSE, 분류는 베르누이 → CE.”

→ 임의 선택 아님, 확률 가정의 결과.

다음 분야로 가도 같은 패턴

  • 분류 (이미지/텍스트): CE
  • 객체 검출: CE + bbox MSE 혼합
  • 시계열 예측: MSE
  • VAE (생성): 가우시안 reconstruction → MSE + KL divergence
  • GAN: 베르누이 → CE (real vs fake)
  • 확률적 강화학습: 카테고리 → CE (정책)

→ 딥러닝 손실 함수 거의 다 MLE 의 한 형태. 이름만 다를 뿐.

한 줄 정리

MSE = “가우시안 노이즈 회귀의 MLE 손실” Cross-entropy = “베르누이/카테고리 분류의 MLE 손실”

둘 다 우리가 배운 MLE 위계의 자연스러운 인스턴스. Stage 1 (동전) + Stage 2 (가우시안) 직관 그대로 머신러닝 손실 함수 전체로 일반화.

14. 정리 — 두 stage 의 흐름

Stage 1: 동전 (이산)
    데이터 HHTHT
        ↓
    L(θ) = θ³(1−θ)²        ← 곱
        ↓ log
    ℓ(θ) = 3log θ + 2log(1−θ)   ← 합
        ↓ 미분 = 0
    θ* = 3/5
        ↓
    "관찰 빈도" — 직관 일치 ✓

Stage 2: 회귀 (연속)
    데이터 (tᵢ, yᵢ), 가우시안 노이즈 가정
        ↓
    L(w) = ∏ N(yᵢ; ŷᵢ, σ²)         ← 곱
        ↓ log
    ℓ(w) = const − SSE(w)/(2σ²)     ← 합 + 제곱 자동 등장
        ↓ 최대화 = 최소화
    arg max ℓ = arg min SSE  ★
        ↓
    "잔차 제곱합 최소화" — 우리가 풀던 그것 ✓

→ MLE 는 자연스러운 일반 원칙, SSE 는 그 가우시안 특수 케이스.

15. 다음 단계 — Stage 3, 4, 5

이 문서가 잡은 직관 위에 다음을 쌓을 예정:

Stage 3 — Weighted Least Squares (WLS)

  • 데이터마다 다른 노이즈 $\sigma_i$
  • 가중 SSE 자연 등장
  • → “정밀한 센서에 더 의존”

Stage 4 — MAP & Regularization

  • prior $P(w)$ 추가 → Bayesian
  • 가우시안 prior → L2 regularization 자연 등장
  • LM 의 $\lambda$ 가 사실 prior 의 강도 ★

Stage 5 — IK 와 연결

  • IK 도 본질적으로 비선형 최소제곱
  • 센서 노이즈 다를 때 → 가중 IK
  • DLS (Damped Least Squares) = LM = MAP 의 가우시안 prior

→ 우리가 푸는 모든 게 결국 확률론적으로 정당화 됨.

16. 핵심 한 줄 요약

“가우시안 노이즈 가정 + MLE = SSE 최소화”

우리가 지금까지 푼 모든 것은, 암묵적으로 가우시안 가정 한 MLE 였음.
