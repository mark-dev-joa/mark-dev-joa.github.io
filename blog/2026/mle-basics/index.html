Part 2·1 최대우도추정(MLE) — 동전과 가우시안

Created on April 27, 2026 by mark

2026   ·   mle   likelihood   gaussian   sse   cross-entropy   statistics   ·   math   optimization

비선형 피팅에서 잔차 제곱합 (SSE) 을 목적 함수로 삼아 GN, LM 등으로 풀어왔다. 그 절차는 직관적으로는 자연스럽지만, 왜 하필 잔차의 제곱이며 모든 데이터에 같은 가중치를 주는지에 대한 정당화는 따로 필요하다. 그 정당화를 제공하는 틀이 최대우도추정 (MLE, Maximum Likelihood Estimation) 이다. 노이즈가 가우시안이라는 가정 하에서 MLE 를 전개하면 SSE 최소화가 자동으로 도출된다.

이 문서는 두 단계로 나뉜다. 1단계에서는 동전 던지기를 통해 likelihood 와 MLE 의 직관을 잡고, 2단계에서는 가우시안 노이즈 가정 위에서 MLE 를 전개하여 SSE 가 자연스럽게 등장하는 과정을 본다.

Stage 1 — 동전 던지기로 본 MLE 의 직관

1. 확률 과 Likelihood

확률 ($P(D \mid \theta)$) 과 likelihood ($L(\theta \mid D)$) 는 같은 식을 다른 시점에서 본 것이다. 확률은 파라미터 $\theta$ 를 고정하고 데이터 $D$ 를 변수로 본다. 동전이 공정하다는 가정 ($\theta = 0.5$) 아래 다섯 번 던져 HHTHT 가 나올 확률을 묻는 식이다. Likelihood 는 반대로 데이터 $D$ 를 고정하고 파라미터 $\theta$ 를 변수로 본다. HHTHT 라는 관측을 본 후, 어떤 $\theta$ 가 이 데이터를 가장 그럴듯하게 만드는지를 묻는다.

  확률 $P(D \mid \theta)$ Likelihood $L(\theta \mid D)$
변수 데이터 $D$ 파라미터 $\theta$
고정 파라미터 $\theta$ 데이터 $D$
합 모든 $D$ 에 대해 합 = 1 합이 1 일 필요 없음 (확률분포 아님)
질문 이 파라미터일 때 이 데이터가 나올 가능성은? 이 데이터를 본 후, 어떤 파라미터가 가장 그럴듯한가?

수식의 형태는 동일하지만 무엇을 변수로 보느냐에 따라 의미가 정반대가 된다.

2. 동전 던지기 — 가장 단순한 MLE

모델은 단일 파라미터 $\theta$ 로 결정된다. 동전을 한 번 던졌을 때 앞이 나올 확률이 $\theta$, 뒤가 나올 확률이 $1 - \theta$ 이며 각 던짐은 독립이다. 다섯 번 던져 HHTHT (앞 3, 뒤 2) 가 관측되었다고 하자.

각 던짐의 확률을 독립 가정에 따라 곱하면 likelihood 가 얻어진다.

\[L(\theta) = P(H) \cdot P(H) \cdot P(T) \cdot P(H) \cdot P(T) = \theta \cdot \theta \cdot (1-\theta) \cdot \theta \cdot (1-\theta)\] \[L(\theta) = \theta^3 (1-\theta)^2\]

이것은 $\theta$ 의 1 차원 함수이며, 이 함수의 최댓값을 주는 $\theta$ 가 MLE 추정값이다.

미분으로 풀기

먼저 log 를 취해 곱을 합으로 바꾼다 (로그를 취하는 이유는 다음 절에서 다룬다).

\[\ell(\theta) = \log L(\theta) = 3 \log \theta + 2 \log(1-\theta)\]

$\theta$ 에 대해 미분한다.

\[\frac{d\ell}{d\theta} = \frac{3}{\theta} - \frac{2}{1-\theta}\]

이 미분에는 두 가지 로그 미분 규칙이 사용되었다. 하나는 자연로그의 기본 미분 $\dfrac{d}{dx}\log x = \dfrac{1}{x}$ 이고, 다른 하나는 연쇄법칙으로 합성된 로그의 미분 $\dfrac{d}{dx}\log f(x) = \dfrac{f’(x)}{f(x)}$ 이다. 후자는 $u = f(x)$ 로 치환하여 $\dfrac{d \log u}{dx} = \dfrac{1}{u} \cdot f’(x)$ 로 유도된다.

항 미분 결과 적용 규칙
$3 \log \theta$ $\dfrac{3}{\theta}$ 기본 로그 미분 (상수 3 곱하기)
$2 \log(1-\theta)$ $\dfrac{2 \cdot (-1)}{1-\theta} = -\dfrac{2}{1-\theta}$ 연쇄법칙 ($f = 1-\theta$, $f’ = -1$)

극값 조건 $d\ell/d\theta = 0$ 을 풀면 다음과 같다.

\[\frac{3}{\theta} = \frac{2}{1-\theta} \;\;\Rightarrow\;\; 3(1-\theta) = 2\theta \;\;\Rightarrow\;\; 5\theta = 3\] \[\theta_{\text{MLE}} = \frac{3}{5} = 0.6\]

다섯 번 중 세 번 앞이 나왔으므로 가장 그럴듯한 $\theta$ 가 관찰 빈도 $3/5$ 와 일치한다. MLE 가 직관적인 추정량을 자동으로 도출하는 첫 사례다. 일반화하면, $N$ 번 중 앞이 $k$ 번 나왔을 때 likelihood 는 $L(\theta) = \theta^k (1-\theta)^{N-k}$ 이고 MLE 추정값은 $\theta_{\text{MLE}} = k/N$ 이다.

3. log-likelihood 를 쓰는 이유

세 가지 실용적 이유가 있다. 첫째, 곱이 합으로 바뀐다. $N$ 개의 데이터에 대한 likelihood 는 곱의 형태 $L(\theta) = \prod_{i=1}^{N} P(x_i \mid \theta)$ 인데, 로그를 취하면 $\ell(\theta) = \sum_{i=1}^{N} \log P(x_i \mid \theta)$ 가 되어 미분이 훨씬 단순해진다.

둘째, 수치 안정성이 확보된다. $N$ 이 커지면 작은 확률들의 곱 $L = 0.01 \times 0.02 \times \cdots$ 은 $10^{-200}$ 같은 값으로 떨어져 부동소수점에서 언더플로우가 발생한다. 로그 영역에서는 같은 양이 $\log L = -460$ 정도의 값으로 표현되어 안전하다.

셋째, 최댓값의 위치는 보존된다. $\log$ 는 단조증가 함수이므로 $L(\theta)$ 의 최댓값을 주는 $\theta$ 와 $\ell(\theta)$ 의 최댓값을 주는 $\theta$ 는 동일하다. 무엇을 최대화하든 같은 답이 나온다.

4. 인터랙티브 데모 — 동전 MLE

상단 곡선은 likelihood $L(\theta) = \theta^k (1-\theta)^{N-k}$, 하단 곡선은 log-likelihood $\ell(\theta) = k \log\theta + (N-k)\log(1-\theta)$ 이다. 빨간 점과 선은 슬라이더로 선택한 현재 $\theta$ 를, 별 표시는 MLE 추정값 $\theta^* = k/N$ 을 나타낸다. 슬라이더로 후보 파라미터를 움직이며 likelihood 값의 변화를 확인하고, 앞면과 뒷면 수를 바꿔 데이터가 늘어날수록 곡선이 뾰족해지는 (확신이 증가하는) 모습을 관찰할 수 있다.

세 가지 실험이 의미 있다. 앞 3 뒤 2 와 앞 30 뒤 20 은 비율은 같지만 (MLE = 0.6), 후자가 훨씬 뾰족한 곡선을 만든다. 앞 1 뒤 0 같은 극단 케이스에서는 MLE = 1.0 이 나오지만, 데이터 부족으로 인한 불안정한 추정임을 곡선의 폭으로 알 수 있다.

5. MLE 의 일반 절차

MLE 는 다음 여섯 단계의 패턴을 따른다. 동전 예에 대응시켜 정리하면 다음과 같다.

단계 동전 예
1. 데이터 HHTHT
2. 모델 $P(H) = \theta$
3. Likelihood $L = \theta^3 (1-\theta)^2$
4. log $\ell = 3\log\theta + 2\log(1-\theta)$
5. 미분 = 0 $3/\theta - 2/(1-\theta) = 0$
6. 풀기 $\theta^* = 3/5$

이 패턴은 모든 MLE 문제에서 동일하다. 다음 단계에서 같은 패턴을 연속 데이터와 가우시안 노이즈에 적용하면 SSE 가 자연스럽게 등장한다.

Stage 2 — 가우시안 노이즈 위에서 SSE 가 등장하는 과정

이 단계의 결론은 한 등식에 압축된다.

\[\ell(w) = C - \frac{\text{SSE}(w)}{2\sigma^2}\]

이 등식은 likelihood 라는 확률론적 양과 SSE 라는 최적화 목적 함수를 직접 연결한다. 좌변을 최대화하는 $w$ 와 우변의 SSE 를 최소화하는 $w$ 가 정확히 같다. 통계 시점의 MLE 와 최적화 시점의 GN/LM 이 같은 답에 도달하는 이유가 여기에 있다. 아래 절들은 이 등식을 유도하고, 그 직관을 조명하며, 응용 사례를 짚는다.

6. 회귀 문제의 확률 모델

데이터는 $(t_i, y_i)$, $i = 1, \dots, N$ 형태로 주어지고, 모델은 비선형 피팅에서 다뤘던 $\hat{y}(t; w) = e^{-wt}$ 를 그대로 사용한다. 핵심 가정은 관측값이 진짜 모델값에 가우시안 노이즈가 더해진 형태라는 것이다.

\[y_i = \hat{y}(t_i; w) + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)\]

노이즈 평균은 0 (편향 없음), 분산은 $\sigma^2$ (모든 데이터에서 동일), 각 $\epsilon_i$ 는 독립이다. 이 가정 아래 $y_i$ 자체도 가우시안을 따르며 그 평균이 모델값이다.

\[y_i \sim \mathcal{N}\big(\hat{y}(t_i; w), \; \sigma^2\big)\]

각 점마다 자기 가우시안

흔한 오해는 모든 데이터가 하나의 가우시안 분포 안에 있다는 그림이다. 실제로는 각 $t_i$ 위에 독립된 자기만의 가우시안 종이 세워지며, 종의 중심은 모델 곡선 $\hat{y}(t_i; w)$ 를 따라가고 데이터 점은 그 종 안에서 흩어진 한 샘플이다.

  단순 측정 (오해된 그림) 회귀 (실제)
가우시안 개수 1 개 $N$ 개 (점마다 하나)
평균 한 값을 공유 각 점마다 다름 ($\mu_i = \hat{y}_i$)
분산 한 값을 공유 한 값을 공유 ($\sigma^2$, 가정)

$\hat{y}_i$ 자체는 결정적인 한 값이지만, $y_i$ 의 분포를 정의하는 평균으로 작동한다. 즉 $\mathbb{E}[y_i] = \mathbb{E}[\hat{y}_i + \epsilon_i] = \hat{y}_i$ 이며, 회귀 일반론의 표현으로는 $\mathbb{E}[y \mid t] = f(t; w)$ 가 된다. 모델은 $y$ 의 조건부 평균을 예측하는 함수다.

7. Likelihood 식의 구성

한 점의 확률 밀도는 가우시안 PDF 로 주어진다.

\[P(y_i \mid w) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}(t_i; w))^2}{2\sigma^2}\right)\]

PDF 값과 확률은 구별해야 한다. PDF 값이 $5.91$ 처럼 1 보다 큰 경우가 자주 나타나는데, 이것은 확률이 아니라 단위 $y$ 당 확률 밀도이며 1 을 넘을 수 있다. 이산 확률은 한 점의 값이 곧 확률이지만, 연속 확률에서는 한 점 근처의 밀도이며 진짜 확률은 PDF 를 일정 구간에 대해 적분해야 얻어진다. PDF 값 자체는 그 관측이 모델에 얼마나 잘 맞는지를 나타내는 척도로 쓰이며, 값이 클수록 모델과 잘 부합한다.

각 점의 관측이 독립이라는 가정 하에 전체 데이터의 likelihood 는 곱이 된다.

\[L(w) = \prod_{i=1}^{N} P(y_i \mid w) = \prod_{i=1}^{N} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)\]

여기서 $\hat{y}_i = \hat{y}(t_i; w)$ 는 줄임 표기다. 이 양은 $w$ 의 함수이며, 이를 최대화하는 $w$ 가 MLE 추정값이다.

8. log 적용으로 SSE 도출

$L(w)$ 에 로그를 취한다.

\[\ell(w) = \log L(w) = \sum_{i=1}^{N} \log P(y_i \mid w)\]

한 점의 로그를 펼치면 다음과 같다.

\[\log P(y_i \mid w) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\]

첫 항은 $w$ 와 무관한 상수이며, 두 번째 항만이 $w$ 에 의존한다. $N$ 개를 모두 더하면 다음 식이 얻어진다.

\[\ell(w) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2\]

여기서 합 부분은 정확히 SSE 의 정의 $\text{SSE}(w) = \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$ 이다. 상수항을 $C$ 로 묶으면 핵심 등식이 얻어진다.

\[\ell(w) = C - \frac{1}{2\sigma^2} \cdot \text{SSE}(w)\]

이 식은 likelihood 와 SSE 를 다리 놓는 결과다. $C$ 는 $w$ 무관한 양수 상수이고, 두 번째 항은 SSE 가 음이 아니므로 항상 음수이며 $w$ 에 따라 변한다. $\ell$ 의 변화는 두 번째 항에서만 비롯된다.

최대화와 최소화의 동치성

$\ell(w)$ 를 최대화하려면 빼는 양 $\text{SSE}(w)/(2\sigma^2)$ 를 작게 해야 하고, 이는 곧 $\text{SSE}(w)$ 를 최소화하는 것과 같다. 한 단계씩 풀면 다음과 같은 논리 체인이 된다. $\ell = C - \text{SSE}/(2\sigma^2)$ 에서 $C$ 는 고정이므로, 빼는 양이 작을수록 $\ell$ 이 크다. 그러므로 $\arg\max_w \ell(w) = \arg\min_w \text{SSE}(w)$ 가 성립한다.

수치로 확인하면 더 명확하다 ($\sigma = 0.05$, $C = 10$ 가정).

SSE $-\text{SSE}/(2\sigma^2)$ $\ell$
0.01 $-2$ $8$ (최대)
0.1 $-20$ $-10$
1.0 $-200$ $-190$

SSE 가 클수록 $\ell$ 이 더 음수쪽으로 끌려가고, SSE 가 가장 작을 때 $\ell$ 이 최대가 된다. 결국 다음 등식이 성립한다.

\[\arg\max_w \ell(w) = \arg\min_w \text{SSE}(w)\]

같은 일을 두 시점에서 본 것이며, $\ell$ 시점에서는 양 (likelihood) 을 키우는 최대화 문제로, SSE 시점에서는 음 (잔차 제곱합) 을 줄이는 최소화 문제로 표현된다.

직관 — 잔차가 커지면 확률이 작아지는 이유

가우시안 PDF 의 식 자체가 답을 준다.

\[P(y) \propto \exp\!\left(-\frac{r^2}{2\sigma^2}\right), \quad r = y - \hat{y}\]

지수 안에 $-r^2$ 가 있으므로 잔차가 커지면 확률 밀도가 빠르게 0 으로 감쇠한다. $\sigma = 1$ 에서 잔차에 따른 PDF 변화는 다음 표와 같다.

잔차 $r$ $r^2$ $\exp(-r^2/2)$
0 0 $1.00$ (최대)
1 1 $0.61$
2 4 $0.14$
3 9 $0.011$
5 25 $4 \times 10^{-6}$

잔차가 5σ 떨어지면 확률 밀도는 사실상 0 에 가깝다. 점별로 $\log P(y_i) \propto -r_i^2$ 이므로 모든 점을 더하면 $\log L \propto -\sum_i r_i^2 = -\text{SSE}$ 가 되어, SSE 가 커지면 log-likelihood 가 작아진다. 좋은 $w$ 는 모든 점을 종의 중심 가까이에 위치시켜 각 점의 확률을 크게 만들고, 동시에 잔차도 작게 만든다. 가우시안 식의 $-r^2$ 한 줄이 MLE 와 SSE 의 동치성을 압축하고 있다.

9. 의문 해소 — 왜 제곱이고 왜 같은 가중치인가

잔차에 제곱을 쓰는 이유는 가우시안 PDF 의 지수 안에 $(y - \mu)^2$ 가 들어 있기 때문이다.

\[P \propto \exp\left(-\frac{(y - \mu)^2}{2\sigma^2}\right)\]

로그를 취하면 자연스럽게 제곱항이 남는다. 즉 SSE 의 제곱은 임의의 선택이 아니라 가우시안 노이즈 가정의 직접적 결과다. 절댓값이나 4 제곱이 자동으로 등장하지 않는 이유도 같다. 다른 손실 함수는 다른 노이즈 가정에 대응한다.

손실 함수 대응하는 노이즈 분포
제곱 $(y-\hat{y})^2$ 가우시안 $\mathcal{N}(0, \sigma^2)$
절댓값 $\lvert y-\hat{y} \rvert$ 라플라스 (양쪽 지수, outlier 강건)
Huber 가우시안 + 두꺼운 꼬리의 혼합
0/1 (분류) 베르누이

노이즈 모델이 손실 함수를 결정한다. SSE 를 쓴다는 것은 이미 가우시안 노이즈를 가정한 것이다.

모든 데이터에 같은 가중치를 주는 이유 또한 이 유도에서 모든 점의 $\sigma$ 가 동일하다고 가정했기 때문이다. 데이터마다 다른 $\sigma_i$ 를 허용하면 likelihood 식은 다음과 같이 변한다.

\[\ell(w) = \text{const} - \frac{1}{2}\sum_i \frac{(y_i - \hat{y}_i)^2}{\sigma_i^2}\]

이로부터 가중 최소제곱 (Weighted Least Squares) 가 자연스럽게 도출된다.

\[\text{WLS}(w) = \sum_i \frac{(y_i - \hat{y}_i)^2}{\sigma_i^2} = \sum_i w_i \cdot e_i^2, \quad w_i = 1/\sigma_i^2\]

노이즈가 작은 정밀한 데이터의 가중치 $w_i$ 가 커지므로, 추정이 그 데이터에 더 의존하게 된다. 다음 단계의 핵심 주제다.

10. 인터랙티브 데모 — 가우시안 MLE

위쪽 그래프는 데이터 점, 슬라이더 $w$ 가 정의하는 모델 $\hat{y} = e^{-wt}$, 그리고 각 $\hat{y}_i$ 주변에 그려진 가우시안 종이다. 아래쪽 그래프는 $w$ 에 대한 log-likelihood $\ell(w)$ 와 그것에 부호를 반대로 한 $-\ell(w) \propto \text{SSE}(w)$ 를 함께 보여준다.

슬라이더를 움직이면 위 곡선과 종 모양이 따라오며, 각 데이터 점이 종의 어느 위치에 놓이는지를 관찰할 수 있다. 데이터가 종의 중심에 모일 때 $\ell$ 이 최대가 되고 동시에 SSE 가 최소가 된다. $\sigma$ 슬라이더로 종의 폭을 바꿔도 $\ell$ 곡선의 스케일만 변하고 최댓값의 위치는 그대로 유지된다.

11. MLE 와 SSE 최소화는 같은 일

지금까지 비선형 피팅에서 SSE 를 최소화한 것은 사실상 가우시안 노이즈 가정 하의 MLE 를 푼 것이다. 두 시점은 다음과 같이 정리된다.

시점 목적 함수 풀이 도구 결과
손실 시점 $\text{SSE}(w) = \sum r_i^2$ GN, LM, Dogleg $w^*$
확률 시점 $\ell(w) = \log L(w)$ $\partial \ell / \partial w = 0$ $w_{\text{MLE}}$

두 답은 정확히 일치하며 ($w^* = w_{\text{MLE}}$), SSE 최소화는 가우시안 케이스에서의 MLE 의 단축 표현이다. MLE 시점에서 회귀를 푸는 흐름은 다음과 같다. 회귀 문제를 설정하고, 데이터를 가장 그럴듯하게 만드는 $w$ 를 찾는 MLE 로 정식화한 뒤, 가우시안 가정을 도입하여 SSE 최소화 문제로 변환한다. 비선형이면 직접 풀 수 없으므로 GN, LM, Dogleg, Newton 같은 반복 알고리즘을 동원하여 컴퓨터로 푼다. GN 과 LM 은 MLE 를 풀기 위한 도구다.

12. 위계 — 확률 가정에서 알고리즘까지

MLE 의 구조는 모든 ML 및 통계 추정에 공통된 보편 패턴을 형성한다. 확률 모델 가정이 likelihood 를 정의하고, 이로부터 손실 함수가 도출되며, 마지막으로 적절한 반복 알고리즘이 그 손실을 최소화한다. 노이즈 가정이 무엇이냐에 따라 도출되는 손실 함수가 달라진다.

노이즈 가정 도출되는 손실 함수 사용 분야
가우시안 $\mathcal{N}(0, \sigma^2)$ MSE / SSE 회귀, IK, 번들 조정
라플라스 MAE / LAD ($\sum \lvert r \rvert$) 강건 회귀
베르누이 Cross-entropy 이진 분류
카테고리 Softmax + CE 다중 분류
포아송 Poisson loss 카운트 데이터
Huber Huber loss outlier 강건

모든 ML 손실 함수는 어떤 분포 가정의 MLE 도출 결과이며, 임의의 선택이 아니다. 우리가 다룬 비선형 피팅은 이 위계의 한 인스턴스에 해당한다.

단계 우리 케이스
가정 가우시안 노이즈
MLE $L = \prod \mathcal{N}(y_i; \hat{y}_i, \sigma^2)$
손실 도출 $\text{SSE} = \sum (y_i - \hat{y}_i)^2$
알고리즘 GN, LM, Dogleg, Newton
답 $w^* \approx 0.5$

새로운 문제에 접근할 때 이 위계는 강력한 가이드가 된다. 노이즈가 어떤 분포를 따를지를 먼저 결정하면 MLE 정식화가 자동으로 손실 함수를 도출하고, 손실의 형태를 보고 적절한 알고리즘을 선택할 수 있다. 어떤 손실을 써야 할지의 막막함은 대부분 확률 가정의 부재에서 비롯된다.

13. MSE 와 Cross-entropy — 위계의 두 대표 인스턴스

MLE 위계의 가장 흔한 두 응용이 MSE 와 cross-entropy 다. 머신러닝 교과서가 회귀에는 MSE, 분류에는 cross-entropy 를 쓴다고 일관되게 말하는 이유가 이 위계에 있다.

MSE 는 SSE 를 데이터 개수로 정규화한 형태다.

\[\text{MSE} = \frac{1}{N}\sum_i (y_i - \hat{y}_i)^2 = \frac{\text{SSE}}{N}\]

데이터 수가 늘어도 스케일이 일정하다는 점에서 손실 비교에 유리하므로 머신러닝 분야에서는 MSE 형태가 널리 쓰인다. 두 양의 $\arg\min$ 은 같으므로 통계학적으로는 동일한 추정량이며, 딥러닝의 loss='mse' 는 정확히 가우시안 노이즈 회귀의 MLE 손실을 가리킨다.

Cross-entropy — 베르누이 가정의 MLE

분류 문제는 $y \in \lbrace 0, 1 \rbrace$ (이진) 또는 $y \in \lbrace 1, \dots, K \rbrace$ (다중) 의 형태이며, 모델은 각 클래스에 속할 확률 $\hat{p}_i = P(y_i = 1)$ 을 출력한다. 이진 분류의 경우 한 점의 likelihood 는 베르누이 분포로 주어진다.

\[P(y_i \mid \hat{p}_i) = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\]

이 식은 Stage 1 의 동전 likelihood 와 동일한 구조다. 로그를 취하고 음수 부호를 붙이면 cross-entropy 손실이 얻어진다.

\[\text{CE} = -\sum_i \big[y_i \log \hat{p}_i + (1 - y_i) \log(1 - \hat{p}_i)\big]\]
정답 $y_i$ 예측 $\hat{p}_i$ 손실 기여
1 0.99 $-\log 0.99 \approx 0.01$
1 0.01 $-\log 0.01 \approx 4.6$
0 0.01 $-\log 0.99 \approx 0.01$
0 0.99 $-\log 0.01 \approx 4.6$

예측이 정답에 가까우면 손실이 0 에 가깝고, 정답에서 멀어질수록 $\log$ 의 발산 특성으로 인해 큰 페널티가 부과된다.

동전 MLE 가 사실 cross-entropy

Stage 1 의 likelihood $L = \theta^k (1-\theta)^{N-k}$ 에 로그를 취하고 음수 부호를 붙인 뒤 점별로 분해하면 다음 식이 된다 ($y_i = 1$ 이 앞면, $y_i = 0$ 이 뒷면).

\[-\ell = -\sum_i \big[y_i \log\theta + (1-y_i)\log(1-\theta)\big]\]

이것은 cross-entropy 그 자체다. Stage 1 의 동전 MLE 는 모든 점이 같은 $\theta$ 를 공유하는 단순화된 cross-entropy 분류로 해석할 수 있다.

위계 표 — 모두 같은 패턴

문제 $y$ 값 분포 가정 likelihood 도출 손실
회귀 실수 가우시안 $\prod e^{-(y-\hat{y})^2/2\sigma^2}/\sqrt{\dots}$ MSE / SSE
이진 분류 0 또는 1 베르누이 $\prod \hat{p}^y(1-\hat{p})^{1-y}$ Cross-entropy
다중 분류 클래스 1~K 카테고리 $\prod \prod_c \hat{p}_c^{y_c}$ CE (소프트맥스)
카운트 자연수 포아송 $\prod e^{-\hat{\lambda}}\hat{\lambda}^y/y!$ Poisson loss

분포 가정에서 likelihood 의 곱을 취하고 로그 + 음수를 통해 손실로 변환하는 절차는 모든 행에서 동일하다. 가우시안에서는 PDF $e^{-r^2/2\sigma^2}/\sqrt{\dots}$ 가 MSE $\sum r^2$ 로 환원되고, 베르누이에서는 $p^y(1-p)^{1-y}$ 가 $-\sum [y \log p + (1-y) \log(1-p)]$ 로 환원된다. 같은 MLE 패턴에 다른 분포만 대입한 결과다.

따라서 회귀에는 MSE, 분류에는 cross-entropy 를 쓴다는 머신러닝의 관행은 데이터의 출력 분포 가정에 따라 MLE 가 자동으로 도출하는 손실의 구체적 형태에 다름 아니다. 임의의 선택이 아니라 확률 가정의 결과다. 분류, 객체 검출, 시계열 예측, VAE, GAN, 강화학습의 정책 손실에 이르기까지 딥러닝에서 사용되는 손실 함수의 대부분은 MLE 의 한 형태이며 이름만 다를 뿐이다.

14. 두 stage 의 흐름 정리

Stage 1 의 동전 (이산) 에서는 데이터 HHTHT 로부터 likelihood $L(\theta) = \theta^3 (1-\theta)^2$ 를 곱으로 구성하고, 로그를 취해 합 $\ell(\theta) = 3\log\theta + 2\log(1-\theta)$ 으로 바꾼 뒤 미분 = 0 을 풀어 $\theta^* = 3/5$ 를 얻었다. 이 답은 관찰 빈도와 일치하며 직관과 부합한다.

Stage 2 의 회귀 (연속) 에서는 가우시안 노이즈 가정 하에서 $L(w) = \prod \mathcal{N}(y_i; \hat{y}_i, \sigma^2)$ 를 구성하고, 로그를 취하면 $\ell(w) = C - \text{SSE}(w)/(2\sigma^2)$ 의 형태가 되어 제곱항이 자동으로 등장한다. $\ell$ 의 최대화는 SSE 의 최소화와 동치이며, 이는 비선형 피팅에서 풀어왔던 그 문제다. MLE 가 보편 원칙이고 SSE 는 그 가우시안 특수 케이스라는 관계가 두 단계의 흐름에 명확히 드러난다.

15. 다음 단계로의 확장

이 문서가 다진 직관 위에 세 단계의 확장을 쌓을 수 있다. 첫째는 가중 최소제곱 (WLS) 으로, 데이터마다 다른 노이즈 $\sigma_i$ 를 허용하면 가중 SSE 가 자연스럽게 도출되고 정밀한 센서에 더 의존하는 추정이 가능해진다. 둘째는 MAP 와 정규화로, prior $P(w)$ 를 도입하면 베이지안 추정이 되며 가우시안 prior 는 L2 정규화를 자연스럽게 도출한다. LM 알고리즘의 $\lambda$ 가 사실은 prior 의 강도에 해당한다는 해석도 이 시점에서 명료해진다. 셋째는 IK 와의 연결로, IK 역시 본질적으로 비선형 최소제곱이며 센서 노이즈가 다를 때 가중 IK 로 확장된다. DLS (Damped Least Squares) 가 곧 LM 이고, 이는 가우시안 prior 를 가진 MAP 와 동치라는 관계가 드러난다. 이 모든 확장의 공통 뿌리는 가우시안 노이즈 가정 하의 MLE 가 SSE 최소화로 환원된다는 한 등식이며, 비선형 피팅에서 다뤄온 모든 절차는 이로써 확률론적으로 정당화된다.
