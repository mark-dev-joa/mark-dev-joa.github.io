가이드 학습 로드맵

학습 로드맵 — 기초부터 컴퓨터 비전, 로보틱스까지

흩어져 있던 글들을 하나의 학습 시리즈 로 다시 엮습니다. 미적분/선형대수/기하 → 비선형 최적화 → MLE → 로봇팔 IK 까지.

이 글은 시리즈의 목차 역할. 새 글이 발행될 때마다 업데이트됩니다.

시리즈 한 줄 요약

“모든 회귀/추정/IK 가 결국 MLE 의 다른 얼굴이다” 를 직접 보여주는 시리즈.

수식 외우기보다 직관 + 인터랙티브 데모 로 이해.

전체 흐름

   수학 기초 (미적분 + 선형대수 + 기하)              
          ↓                                          
   1D 최적화 (미분=0, GD, Newton)                    
          ↓                                          
   비선형 최소제곱 (Gauss-Newton, LM, Dogleg)        
          ↓                                          
   ★ MLE — 위 모든 것의 통일 시점 ★                  
          ↓                                          
   응용:  컴퓨터 비전 (캘리브레이션, optical flow)   
          로보틱스 (FK / IK)

→ MLE 가 척추. 모든 응용 (회귀, 분류, IK, SLAM) 이 이 한 프레임으로 묶임.

📐 Part 0: 수학 기초

기본 도구 — 미분, 테일러, 벡터, 평면/직선.

글 한 줄
자연상수 e 왜 미분/적분에서 $e$ 가 자연스러운지
테일러 급수 함수를 다항식으로 근사하는 도구
연쇄법칙 합성함수 미분의 기본 규칙
벡터의 외적 3D 벡터 연산 + 평면의 법선
동차좌표에서의 외적 컴퓨터 비전의 기본
평면의 방정식 외적의 첫 응용
직선의 방정식 직선/평면 기하

🔧 Part 1: 1D 최적화 기초

미분 = 0 직관에서 출발 → 비선형 최소제곱 → 알고리즘 한판 비교.

# 글 상태
0 Part 1·1 선형 최소제곱과 정규방정식 — 선형 LSE 입문 (Ax=b → 정규방정식) ✓ 발행
1 최적화 이론 기초 — GD, Newton, GN, LM 카탈로그 ✓ 발행
2 에러와 자코비안 정리 — SLAM 시점 MLE + GN 실전 ✓ 발행
3 1D 비선형 피팅 — Gauss-Newton 끝까지 🔜 예정
4 LM, Newton, Dogleg 한판 비교 🔜 예정

🎲 Part 1.5: 확률 입문 (MLE 가기 전 워밍업)

MLE/MAP 본격 들어가기 전 확률 격차 메우기. 다음 5가지만:

# 글 상태
4.5 Part 1·5 확률 입문 — MLE 전에 알아야 할 5가지 ✓ 발행
부록 확률 분포 개관 — 자주 쓰는 10 개 분포 카탈로그 ✓ 발행

다루는 것:

  • 확률 vs 확률 밀도 (PDF 의 정확한 의미, 빵의 밀도 비유)
  • 가우시안 분포 (종 모양, 평균/분산)
  • 표준정규 CDF $\Phi$ + FTC + 다항 근사 (가우시안 적분 풀이)
  • 독립 사건과 곱셈 (왜 ∏)
  • 조건부 확률 P(A|B)
  • 베이즈 정리 (likelihood, prior, posterior)
  • 부록: 균등/지수/베타/감마/포아송 등 10 개 분포 + Lambert W 등 비초등 함수

→ 약하면 Part 2 (MLE) 들어가기 전 잠시 들르기.

🎯 Part 2: MLE 통일 시점 ⭐

확률적 시점에서 보면 모든 손실 함수가 한 뿌리 — MLE 의 자연스러운 도출.

# 글 상태
5+6 Part 2·1 최대우도추정(MLE) — 동전과 가우시안 ✓ 발행
7 Part 2·2 MLE = SSE 의 동치성 — 1D 회귀 검증 ✓ 발행
8 MSE / Cross-entropy 와 ML 위계 🔜 예정
9 Part 2·3 가중 최소제곱 (WLS) — 점마다 다른 노이즈 ✓ 발행
10 Part 2·4 MAP — 사전 지식 추가, LM 의 λ 정체 ✓ 발행

이 Part 의 한 등식:

\[\ell(w) = C - \frac{\text{SSE}(w)}{2\sigma^2}\]

“확률 (likelihood) 시점 ↔ 손실 (SSE) 시점” 을 잇는 다리. ★
