1. 확률 vs 확률 밀도 (PMF vs PDF)

두 종류의 확률 함수

변수 종류 정식 용어 한국어 한 점의 의미
이산 (주사위, 동전) PMF (Probability Mass Function) 확률 질량 함수 그 값의 확률 직접
연속 (키, 시간, 측정) PDF (Probability Density Function) 확률 밀도 함수 단위당 밀도 (확률 ≠)

→ MLE / MAP 는 보통 연속 변수 (PDF) 다룸. PDF 의 미묘함을 정확히 이해하는 게 핵심.

이산 — 주사위, 동전 (PMF)

각 결과의 확률을 직접 줌:

\[P(X = x_k) = p_k\]

예:

  • 주사위: $P(X = 3) = 1/6$
  • 동전: $P(\text{앞}) = 1/2$

→ 각 막대 높이가 그대로 확률 (0~1). → 모든 합 = 1: $\sum_k p_k = 1$.

인터랙티브 — “K 개 선택지 중 하나”

이산 변수 = K 개 가지 중 정확히 하나가 골라지는 상황. 회색 막대가 각 선택지의 진짜 확률, 굴리면 주황 막대 (관측 빈도) 가 점점 회색에 수렴.

해 보기:

  • K=2 (동전), K=6 (주사위) — 균등이면 모두 같은 높이.
  • “100번” 여러 번 누르면 주황이 회색에 점점 가까워짐 (대수의 법칙).
  • 편향 분포로 바꿔보면 — 막대 높이가 다 다르지만 합은 여전히 1.

참고 — 샘플링은 어떻게? (역 누적분포 트릭)

데모가 “굴리기” 누를 때마다 하는 일:

  1. 0~1 균등 난수 한 개 뽑기 (Math.random()).
  2. 확률을 누적합으로 펼쳐서 [0, 1) 을 칸으로 나누기 (칸 너비 = 그 결과의 확률).
  3. 난수가 어느 칸에 떨어졌나 보고, 그 인덱스에 카운트 +1.

K=6 편향 ($p_k = 0.463, 0.255, 0.140, 0.077, 0.042, 0.023$) 을 띠로 펼치면:

→ 난수 0.6 이면 0.463 ~ 0.718 칸 → “2” 카운트. → 칸 너비 ∝ 확률 ⇒ 자주 나오는 결과의 칸이 넓음 ⇒ 자연스럽게 그 결과가 자주 뽑힘.

왜 잘 작동? 균등 난수가 길이 $L$ 인 구간에 떨어질 확률 = $L$. $i$ 번째 칸 너비 = $p_i$. 따라서 결과 $i$ 가 뽑힐 확률 = $p_i$ ✓.

관측 빈도:

\[\text{빈도}_i = \frac{\text{counts}[i]}{N} \;\xrightarrow{N \to \infty}\; p_i \quad \text{(대수의 법칙)}\]

→ 굴릴수록 주황 막대가 회색 막대에 수렴하는 이유.

식으로 정리 — 동전 vs 주사위

1. 동전 (K = 2)

가능한 결과:

\[\Omega = \{\text{앞}, \text{뒤}\}\]

→ 표본 공간 $\Omega$ 가 딱 두 원소.

PMF — 결과별 확률:

\[P(\text{앞}) = p\] \[P(\text{뒤}) = 1 - p\]

→ 파라미터 $p \in [0, 1]$ 하나로 분포 전체가 정해짐.

조건 확인 (PMF 의 두 조건):

  1. 각 값 0~1: $0 \le p \le 1$, $0 \le 1-p \le 1$ ✓
  2. 합 = 1: $P(\text{앞}) + P(\text{뒤}) = p + (1-p) = 1$ ✓

구체적 예:

종류 $p$ $P(\text{앞})$ $P(\text{뒤})$
공정 0.5 0.5 0.5
약한 편향 0.6 0.6 0.4
강한 편향 0.9 0.9 0.1

→ 데모 K=2 에서 “균등” 이 첫 줄, “편향” 이 셋째 줄에 가까움.

2. 주사위 (K = 6, 균등)

가능한 결과:

\[\Omega = \{1, 2, 3, 4, 5, 6\}\]

→ 6 개 눈.

PMF — 결과별 확률 (모두 같음):

\[P(X = 1) = P(X = 2) = P(X = 3) = P(X = 4) = P(X = 5) = P(X = 6) = \frac{1}{6}\]

한 줄로:

\[P(X = k) = \frac{1}{6}, \quad k \in \{1, 2, 3, 4, 5, 6\}\]

→ 파라미터 없음. “균등” 이라는 가정 하나로 분포 결정.

조건 확인:

  1. 각 값: $0 \le \frac{1}{6} \le 1$ ✓
  2. 합:
\[\sum_{k=1}^{6} P(X = k) = \underbrace{\frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6}}_{6 \text{ 항}} = \frac{6}{6} = 1 \;\checkmark\]

구간 확률 — 더하면 됨:

이산 변수의 구간 확률 = 그 안의 값들 확률의 합.

  • “짝수가 나올 확률”:
\[P(X \in \{2, 4, 6\}) = P(X=2) + P(X=4) + P(X=6) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}\]
  • “3 이하”:
\[P(X \le 3) = P(X=1) + P(X=2) + P(X=3) = \frac{3}{6} = \frac{1}{2}\]

→ PDF 와 다른 점: PDF 는 적분, PMF 는 그냥 더하기.

3. 편향 주사위 — 일반화 (카테고리컬, K=6)

데모의 “편향” 옵션이 이 경우. 각 눈마다 확률이 다름:

\[P(X = 1) = p_1, \; P(X = 2) = p_2, \; \ldots, \; P(X = 6) = p_6\]

한 줄로:

\[P(X = k) = p_k, \quad k \in \{1, \ldots, 6\}\]

제약:

\[\sum_{k=1}^{6} p_k = p_1 + p_2 + p_3 + p_4 + p_5 + p_6 = 1\]

→ 자유 파라미터는 5 개 ($p_6 = 1 - p_1 - p_2 - p_3 - p_4 - p_5$ 로 자동 결정).

데모의 편향 분포 (실제로 코드에서 쓰는 식):

⚠️ 이 식은 수학적으로 유도된 게 아니라, 데모에서 “감소하는 막대 모양” 을 만들려고 임의로 고른 등비수열. 비율 $r = 0.55$ 도 시각적 선택.

1단계 — 모양 선택 (자의적): 다음 막대 = 이전 × 0.55 (등비수열).

\[\text{raw}_k = 0.55^{k-1}\]

2단계 — 정규화 (필수): 합 = 1 만족시키려면 합으로 나눔.

\[p_k = \frac{0.55^{k-1}}{\sum_{j=1}^{6} 0.55^{j-1}} = \frac{0.55^{k-1}}{Z}, \quad p_k \propto 0.55^{k-1}\]

여기서 $Z = \sum_j 0.55^{j-1}$ 는 정규화 상수 (베이즈 정리의 $P(D)$ 와 같은 역할).

$Z$ 직접 계산:

\[Z = 1 + 0.55 + 0.3025 + 0.1664 + 0.0915 + 0.0503 = 2.1607\]

(닫힌 형태: $Z = \dfrac{1 - r^K}{1 - r} = \dfrac{1 - 0.55^6}{0.45} \approx 2.1607$)

최종 PMF:

$k$ raw $= 0.55^{k-1}$ $p_k = \text{raw} / 2.1607$
1 1.000 0.463
2 0.550 0.255
3 0.303 0.140
4 0.166 0.077
5 0.092 0.042
6 0.050 0.023
합 2.1607 1.000 ✓

→ 1 이 가장 잘 나오고, 6 으로 갈수록 확률 작아짐. 데모에서 “편향” 골랐을 때 회색 막대 모양과 정확히 같음.

핵심: 모양은 자의적, 정규화는 필수. 어떤 양수 함수 $f(k)$ 든 $p_k = f(k) / \sum f(j)$ 로 만들면 PMF.

세 식의 관계 ★

        카테고리컬 (K개, 확률 다 다름)
             │
             ├── K=2 → 베르누이 (동전)
             │
             └── 모든 p_k 같음 → 균등 (주사위)

→ 카테고리컬이 가장 일반, 동전/주사위는 그 특수 케이스.

공통 조건 (다시 강조)

어떤 PMF 든:

  1. $0 \le p_k \le 1$
  2. $\sum_k p_k = 1$

→ 데모에서 막대 높이 다 더하면 항상 1 인 게 이 조건의 시각화.

연속 — 키, 시간, 측정값 (PDF)

  • 키 = 정확히 175.000… cm 일 확률 = ?
  • 답: 0

→ 무한히 정밀한 한 점은 0 확률.

그럼 어떻게 다루나 — 구간

연속 변수는 구간 의 확률만 의미 있음:

\[P(174 < \text{키} < 176) = \text{어떤 값}\]

이게 진짜 확률.

PDF 의 정체 — “확률 밀도”

PDF $f(x)$ 는 확률 자체가 아니라 단위당 확률 :

\[P(a < X < b) = \int_a^b f(x)\,dx\]

→ 면적이 진짜 확률, PDF 값은 밀도.

인터랙티브 — 키 분포로 적분 직관 잡기

한국 성인 키 ~ $\mathcal{N}(170, 7^2)$ cm 라 가정. 빨간/파란 손잡이를 좌우로 끌어서 구간 $[a, b]$ 를 바꿔봐. 주황 면적 = $P(a < X < b)$.

표기 정리 — $X \sim \mathcal{N}(\mu, \sigma^2)$

기호 뜻
$X$ 확률변수 (예: 키)
$\sim$ “분포를 따른다”
$\mathcal{N}$ Normal (가우시안) 분포
$\mu$ 평균 (첫 번째 자리)
$\sigma^2$ 분산 (두 번째 자리, 표준편차 $\sigma$ 아님 ⚠️)

→ 우리 데모: $\mathcal{N}(170,\, 7^2) = \mathcal{N}(170,\, 49)$, 즉 $\mu = 170$ cm, $\sigma = 7$ cm.

데모가 그리는 식 (가우시안 PDF 에 μ=170, σ=7 대입):

\[f(x) = \frac{1}{\sqrt{2\pi \cdot 7^2}} \, \exp\left(-\frac{(x - 170)^2}{2 \cdot 7^2}\right) = \frac{1}{7\sqrt{2\pi}} \, \exp\left(-\frac{(x - 170)^2}{98}\right)\]

정점 $f(170) = \dfrac{1}{7\sqrt{2\pi}} \approx 0.0570$ /cm. 데모에서 손잡이를 170 에 두면 라벨 f = 0.0570 /cm 로 확인 가능. (식 유도와 적분 계산은 데모 아래 “적분 직접 계산” 섹션에서.)

적분이 어렵게 느껴지면 이렇게 보면 됨:

보는 법 의미
사각형 근사 (PDF × 폭) 폭이 좁을 때 PDF 값이 거의 일정 → “한 칸의 확률”
여러 사각형 합 폭이 넓을 때 PDF 값이 변함 → 잘게 잘라 더한 게 적분
정확한 적분 $\int_a^b f(x)\,dx$ 사각형을 무한히 잘게 한 극한 = 진짜 면적

데모로 확인할 것

  1. 좁게 → 0 으로 점근: “한 점 → 175 ± 0.001” 버튼 누르면 면적이 거의 0. 단일 점 확률 = 0 의 정체 시각화.
  2. ±1σ ⇒ 약 68%, ±2σ ⇒ 약 95%, ±3σ ⇒ 약 99.7% — 가우시안의 유명한 규칙.
  3. PDF × 폭 vs 정확한 적분 비교 — 폭이 좁으면 거의 같음, 폭이 넓으면 차이 남 (PDF 가 구간 안에서 변하니까).
  4. PDF 값 vs 확률 구별 — 화면 안 정보 패널에 “PDF 값 (중앙점)” 과 “정확한 적분” 이 따로 나와. PDF 값은 0.057 같이 작은 수, 면적이 진짜 확률.
  5. 퍼센트 해석 — 패널 맨 아래 노란 박스에 자연스러운 문장으로 표시. 예: “169.5 ~ 170.5 cm 사이 사람 비율 ≈ 5.71%”. 이게 적분 = 확률의 가장 직관적인 의미.

퍼센트 변환 = ×100. 확률 0.057 = 5.7%, 0.6827 = 68.27%, 0.9545 = 95.45% 등. 단위 없는 비율을 사람 친화적으로.

주의 — 패널의 “PDF 값 ≈ 0.057 /cm” 은 확률 5.7% 가 아님. 그건 1cm 폭당 밀도. 실제 5.7% 는 폭 1cm 짜리 적분 값 ($f(170) \times 1$cm). 좁은 구간이면 둘이 거의 같아 보이지만, 단위와 의미가 다름.

적분 직접 계산 — 데모의 숫자로

데모가 화면 뒤에서 어떤 식을 푸는지 단계별로.

1단계 — 가우시안 PDF 식

원형 (일반):

\[f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \, \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)\]

where:

  • $\mu$ — 평균 (분포 중심)
  • $\sigma^2$ — 분산 (퍼짐 정도)
  • $\sigma > 0$ — 표준편차
  • $\dfrac{1}{\sqrt{2\pi\sigma^2}}$ — 정규화 상수 (적분 = 1 만들기 위해)
  • $\exp(-\,\cdot\,)$ — 종 모양을 만드는 핵심

우리 데모 대입 ($\mu = 170$, $\sigma = 7$):

\[f(x) = \frac{1}{\sqrt{2\pi \cdot 7^2}} \, \exp\left(-\frac{(x - 170)^2}{2 \cdot 7^2}\right) = \frac{1}{7\sqrt{2\pi}} \, \exp\left(-\frac{(x - 170)^2}{98}\right)\]

→ 정점 (x=170 일 때):

\[f(170) = \frac{1}{7\sqrt{2\pi}} \approx \frac{1}{17.547} \approx 0.0570\]

데모 패널의 “PDF 값 (중앙점) ≈ 0.0570” 과 정확히 일치.

2단계 — 적분 식 세우기

\[P(a < X < b) = \int_a^b f(x)\,dx = \int_a^b \frac{1}{7\sqrt{2\pi}} \exp\left(-\frac{(x - 170)^2}{98}\right) dx\]

→ 이대로는 닫힌 형태로 못 풂 (가우시안 적분은 초등함수로 표현 불가).

적분 기본 성질 — 잠깐 복습

다음 단계 (치환) 가 갑자기 안 와닿을 수 있어서, 필요한 적분 도구 두 개만.

(1) 상수 빼내기 (선형성):

\[\int_a^b c \cdot f(x)\,dx \;=\; c \int_a^b f(x)\,dx\]

적분 안의 상수는 밖으로 빼도 똑같음. (예: $\int 5x \, dx = 5\int x\, dx$)

(2) 변수 치환 (substitution rule) ⭐ — 핵심.

치환에는 두 가지 표준 형태. 같은 결과를 보는 시점이 다를 뿐.

형태 A — u-치환 (정통 교과서 형태)

식 안에 합성함수 $f(g(x))$ 와 그 미분 $g’(x)$ 가 짝으로 있을 때:

\[\int_a^b f(g(x)) \cdot g'(x)\,dx \;=\; \int_{g(a)}^{g(b)} f(u)\,du\]

“안쪽 함수 $g(x)$ 를 $u$ 로 묶고, $g’(x)\,dx$ 가 자동으로 $du$ 로 흡수”.

작은 예 — $\displaystyle\int 2x \cdot \cos(x^2)\,dx$ 를 천천히

(1) 식 관찰 — 두 부분으로 나눠 보기:

\[\underbrace{\;2x\;}_{\text{앞}} \;\cdot\; \cos(x^2)\] \[2x \;\cdot\; \underbrace{\cos(x^2)}_{\text{뒤}}\]
  • 뒤 $\cos(x^2)$ 는 합성함수: 안에 $x^2$, 바깥에 $\cos$
  • 앞 $2x$ 는 우연일까? — 아니, $x^2$ 의 미분이 $2x$. 앞이 뒤의 안쪽 함수의 미분.

→ 이게 u-치환이 깔끔하게 통하는 신호.

(2) 이름 붙이기:

\[g(x) = x^2 \;\;(\text{안쪽 함수}), \quad f(u) = \cos u \;\;(\text{바깥 함수})\]

원래 식을 이 이름으로 다시 쓰면:

\[\int 2x \cdot \cos(x^2)\,dx = \int g'(x) \cdot f(g(x))\,dx\]

(앞 $2x = g’(x)$, 뒤 $\cos(x^2) = f(g(x))$)

(3) 새 변수 정의 + 미분소 환산:

\[u = g(x) = x^2\]

이 식을 양변 미분:

\[\frac{du}{dx} = 2x \;\;\Rightarrow\;\; du = 2x\,dx\]

→ 핵심: 원래 식에 있던 “$2x\,dx$” 덩어리가 통째로 $du$ 가 됨.

(4) 식 안에 끼워넣기:

치환을 적용:

  • $\cos(x^2) \to \cos u$
  • $2x\,dx \to du$

따라서:

\[\int \cos(x^2) \cdot 2x\,dx \;=\; \int \cos u \, du\]

→ 변수 하나뿐인 깔끔한 형태로 변신.

(5) 적분:

\[\int \cos u\,du = \sin u + C\]

왜 $\sin u + C$ 가 답? — 적분 = 미분 역연산. “미분하면 $\cos u$ 가 되는 함수가 누구지?” 의 답이 $\sin u$.

보조 — 왜 $(\sin u)’ = \cos u$ 인가

미분의 정의로 풀면:

\[\frac{d}{du}\sin u = \lim_{h \to 0} \frac{\sin(u + h) - \sin u}{h}\]

사인 덧셈 공식 $\sin(u+h) = \sin u \cos h + \cos u \sin h$ 대입:

\[= \lim_{h \to 0} \left[\sin u \cdot \frac{\cos h - 1}{h} + \cos u \cdot \frac{\sin h}{h}\right]\]

두 가지 유명한 극한 ($h \to 0$):

\[\lim_{h \to 0} \frac{\sin h}{h} = 1, \qquad \lim_{h \to 0} \frac{\cos h - 1}{h} = 0\]

대입:

\[= \sin u \cdot 0 + \cos u \cdot 1 = \cos u \;\;\checkmark\]
기하학적 직관 — 단위원

각도 $u$ 에서 단위원 위 점은 $(\cos u, \sin u)$. $u$ 가 늘어남에 따라 점이 원 위를 움직이고, 그 속도 = 위치의 미분 = 접선 방향 $(-\sin u, \cos u)$.

각 성분 미분:

\[\frac{d}{du}\cos u = -\sin u, \qquad \frac{d}{du}\sin u = \cos u\]
왜 “+ C” 가 붙나

상수의 미분은 항상 0. 따라서:

\[\frac{d}{du}(\sin u + 7) = \cos u, \quad \frac{d}{du}(\sin u - 100) = \cos u, \quad \frac{d}{du}(\sin u + C) = \cos u\]

→ 미분하면 $\cos u$ 가 되는 함수가 무수히 많음 (상수만 다름). 부정적분은 이 모든 가능성을 한꺼번에 표현하려고 임의 상수 $C$ 를 붙임.

검증

미분해서 원래로 돌아가는지 확인:

\[\frac{d}{du}\left[\sin u + C\right] = \cos u + 0 = \cos u \;\;\checkmark\]

(6) 원래 변수 $x$ 로 복귀 — $u = x^2$ 다시 대입:

\[= \sin(x^2) + C\]

(7) 검증 — 미분해서 원래로 돌아가나:

\[\frac{d}{dx}\left[\sin(x^2)\right] = \cos(x^2) \cdot 2x \;\;\checkmark\]

→ 원래 피적분 함수와 정확히 같음.

한 줄 정리:

“$2x\,dx$ 가 식에 마침 있어서 $du$ 로 흡수” 가 u-치환 트릭의 본질. 안쪽 함수의 미분이 식에 보일 때만 통함.

형태 B — 변수 변환 (강제 환산)

식에 $g’(x)$ 가 안 보여도, 강제로 $z = g(x)$ 정의하고 미분소만 환산:

\[\int_a^b F(x)\,dx \;=\; \int_{g(a)}^{g(b)} F(x(z)) \cdot \frac{dx}{dz}\,dz\]

세 가지 동시 환산:

  1. 변수: $x$ → $z$ (식 안 모든 $x$ 를 $z$ 표현으로)
  2. 적분 한계: $a, b$ → $g(a), g(b)$
  3. 미분소: $dx$ → $\dfrac{dx}{dz}\,dz$ (스케일 보정)

왜 폭 보정이 필요하나

적분은 “사각형들의 합” (가로 = 폭, 세로 = 함수값). 변수 단위가 바뀌면 폭의 의미도 바뀜.

$z$ 가 1 늘어날 때 $x$ 는 얼마 늘어나?
$z = (x - 170) / 7$ $x$ 는 7 늘어남

→ $dz = 1$ 이 $dx = 7$ 에 대응. 그래서 $dx = 7\,dz$. 이 환산을 안 하면 면적이 7배 작아져서 답 틀림.

두 형태 어느 걸 쓰나

  • 형태 A — 식 안에 $g’(x)$ 가 이미 있으면 자연스러움. 정통.
  • 형태 B — 그게 안 보일 때도 무조건 통함. 학습용으로 이해 쉬움.
  • 가우시안 표준화는 둘 다 적용 가능 — 다음 단계에선 형태 B 로 풀고, 그 아래 형태 A 시점도 한 번 더 보여줄게.

3단계 — 표준화 치환 $z = (x - \mu) / \sigma$

이제 위 도구 적용. 목표: 변수 바꿔서 표준정규 $\mathcal{N}(0, 1)$ 모양으로 통일.

구체적 케이스로 진행 — 데모 프리셋 ±1σ:

\[P(163 < X < 177) = \int_{163}^{177} \frac{1}{7\sqrt{2\pi}} \exp\left(-\frac{(x-170)^2}{98}\right) dx\]

→ 답이 0.6827 (= 68.27%) 가 나와야 함. 처음부터 끝까지 따라가보자.

(3-1) 치환 정의 — $z$ 는 $x$ 의 새 함수

\[z = \frac{x - 170}{7} \quad \Leftrightarrow \quad z = g(x) \text{ 라는 함수}\]

→ $z$ 는 그냥 새 이름이 아니라 $x$ 의 함수. 입력 $x$ 하나 → 출력 $z$ 하나.

$z$ 의 의미 — z-score:

$x$ (cm) $z = (x - 170) / 7$ 의미
170 0 평균
177 +1 평균 위로 1σ
184 +2 평균 위로 2σ
163 −1 평균 아래로 1σ
156 −2 평균 아래로 2σ

기하학적 의미:

  1. 평행이동: $x - 170$ → 분포 중심을 0 으로 이동 (μ = 0)
  2. 스케일링: $/ 7$ → 가로 폭을 1 단위로 압축 (σ = 1)

→ 결과: 어떤 가우시안이든 표준정규 $\mathcal{N}(0,1)$ 로 변환. 한 표 ($\Phi$ 표) 로 모든 가우시안 처리.

(3-2) 세 가지 동시 환산

치환은 항상 변수 + 미분소 + 적분 한계 를 동시에 바꿈.

(a) 변수 — $x$ 로 풀기:

\[x = 7z + 170\]

(b) 미분소 — $z$ 로 미분 후 $dz$ 곱:

\[\frac{dx}{dz} = 7 \;\Rightarrow\; dx = 7\,dz\]

(c) 적분 한계 — [163, 177] → $z$ 좌표:

\[z_a = \frac{163 - 170}{7} = -1\] \[z_b = \frac{177 - 170}{7} = +1\]

→ ±1σ 가 $z$ 좌표로 정확히 [-1, +1].

(3-3) 식 안 표현 환산

지수부 $(x-170)^2 / 98$ 를 $z$ 로:

\[x - 170 = 7z \;\Rightarrow\; (x-170)^2 = 49 z^2\] \[\frac{(x-170)^2}{98} = \frac{49 z^2}{98} = \frac{z^2}{2}\]

→ 깔끔하게 $z^2 / 2$.

(3-4) 끼워넣기 + 약분

원래:

\[\int_{163}^{177} \frac{1}{7\sqrt{2\pi}} \exp\left(-\frac{(x-170)^2}{98}\right) dx\]

치환 → 변수 / 한계 / $dx$ / 식안 모두 바꿈:

\[= \int_{-1}^{+1} \frac{1}{7\sqrt{2\pi}} \, e^{-z^2/2} \cdot 7\,dz\]

상수 $\dfrac{1}{7} \cdot 7 = 1$ → 약분:

\[= \int_{-1}^{+1} \frac{1}{\sqrt{2\pi}} \, e^{-z^2/2}\,dz\]

→ σ 와 μ 가 식에서 사라짐. 모든 가우시안이 표준정규 한 식으로 환산되는 이유.

(3-5) (참고) 형태 A 시점으로 다시 보기

같은 일을 u-치환 정통 형태로 보면 — 상수를 쪼개면 $g’(x) = 1/7$ 가 자연스럽게 등장:

\[\frac{1}{7\sqrt{2\pi}} \exp\left(-\frac{(x-170)^2}{98}\right) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{g(x)^2}{2}\right) \cdot \frac{1}{7}\]

여기서 우측 식의 두 부분이 각각:

  • $\dfrac{1}{\sqrt{2\pi}} \exp\left(-\dfrac{g(x)^2}{2}\right) = f(g(x))$ — 합성함수
  • $\dfrac{1}{7} = g’(x)$ — 안쪽 함수의 미분

→ 정확히 형태 A 의 $f(g(x)) \cdot g’(x)$ 모양. u-치환 공식 그대로 적용:

\[\int_a^b f(g(x)) g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\]

→ 결과 동일. 두 형태는 같은 일을 다른 시점에서 본 것.

4단계 — FTC 로 정적분 전개 (위 − 아래)

미적분 기본 정리 (FTC) 복습

$f$ 의 부정적분 (역도함수) 이 $F$ 라고 할 때 — 즉 $F’(x) = f(x)$ — 정적분은:

\[\int_a^b f(x)\,dx = F(b) - F(a) = \big[F(x)\big]_a^b\]

→ 위 한계의 값 빼기 아래 한계의 값 (위 − 아래).

작은 예 — $\int_0^3 2x\,dx$:

부정적분 $\int 2x\,dx = x^2 + C$, 즉 $F(x) = x^2$. FTC 적용:

\[\int_0^3 2x\,dx = \big[x^2\big]_0^3 = 3^2 - 0^2 = 9\]

→ 끝. 다항 근사 불필요. 부정적분이 초등이면 FTC 만으로 끝.

표준정규 PDF 의 부정적분 = $\Phi$

표준정규 누적분포:

\[\Phi(z) := \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-t^2/2}\,dt, \quad \Phi'(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}\]

→ 표준정규 PDF 의 부정적분. 단, $\Phi$ 는 비초등 — 닫힌 식 없음.

우리 적분에 FTC 적용

3단계 끝에서 얻은 적분:

\[\int_{-1}^{+1} \frac{1}{\sqrt{2\pi}} e^{-z^2/2}\,dz = \big[\Phi(z)\big]_{-1}^{+1} = \Phi(+1) - \Phi(-1)\]

→ 같은 틀, 부정적분이 초등이냐 비초등이냐만 다름.

적분 예제 모음 — 다항식부터 가우시안까지

A. 다항식 — FTC 만으로 끝

A1. $\displaystyle\int_0^3 2x\,dx$

단계 식
부정적분 $\int 2x\,dx = x^2 + C$
FTC $\big[x^2\big]_0^3 = 3^2 - 0^2$
답 $\mathbf{9}$

→ 직선 $y = 2x$ 의 [0, 3] 삼각형 면적 ($\tfrac{1}{2} \cdot 3 \cdot 6 = 9$).

A2. $\displaystyle\int_1^2 x^3\,dx$

단계 식
부정적분 $\int x^3\,dx = \dfrac{x^4}{4} + C$
FTC $\left[\dfrac{x^4}{4}\right]_1^2 = \dfrac{16}{4} - \dfrac{1}{4}$
답 $\mathbf{\dfrac{15}{4}} = 3.75$

A3. $\displaystyle\int_0^2 (x^3 + 2x^2 + 3x)\,dx$

단계 식
부정적분 $\dfrac{x^4}{4} + \dfrac{2x^3}{3} + \dfrac{3x^2}{2} + C$
FTC ($F(2) - F(0)$) $\left(4 + \dfrac{16}{3} + 6\right) - 0$
답 $\mathbf{\dfrac{46}{3}} \approx 15.33$

A4. $\displaystyle\int_{-1}^{2} (3x^2 - 2x + 1)\,dx$

단계 식
부정적분 $x^3 - x^2 + x + C$
위 한계 $F(2) = 8 - 4 + 2 = 6$
아래 한계 $F(-1) = -1 - 1 - 1 = -3$
FTC $6 - (-3)$
답 $\mathbf{9}$

B. 일반 초등함수 — FTC 로 깔끔

B1. $\displaystyle\int_0^\pi \sin x\,dx$

단계 식
부정적분 $\int \sin x\,dx = -\cos x + C$
FTC $\big[-\cos x\big]_0^\pi = -\cos\pi - (-\cos 0) = 1 + 1$
답 $\mathbf{2}$

→ 사인 곡선 한 봉우리 면적 = 2.

B2. $\displaystyle\int_0^{\pi/2} \cos x\,dx$

단계 식
부정적분 $\int \cos x\,dx = \sin x + C$
FTC $\big[\sin x\big]_0^{\pi/2} = \sin(\pi/2) - \sin 0 = 1 - 0$
답 $\mathbf{1}$

B3. $\displaystyle\int_0^1 e^x\,dx$

단계 식
부정적분 $\int e^x\,dx = e^x + C$
FTC $\big[e^x\big]_0^1 = e^1 - e^0 = e - 1$
답 $\mathbf{e - 1} \approx 1.718$

→ 지수함수의 신기한 자기복제: 미분 / 적분 모두 $e^x$.

B4. $\displaystyle\int_1^e \dfrac{1}{x}\,dx$

단계 식
부정적분 $\int \dfrac{1}{x}\,dx = \ln x + C$
FTC $\big[\ln x\big]_1^e = \ln e - \ln 1 = 1 - 0$
답 $\mathbf{1}$

→ 자연로그의 정의: “$1/x$ 곡선 아래 면적이 1 이 되는 지점” = $e$.

C. u-치환 활용 — 가우시안과 같은 패턴

C1. $\displaystyle\int_0^1 2x \cdot \cos(x^2)\,dx$

치환: $u = x^2$, $du = 2x\,dx$, 한계 $0 \to 1$.

단계 식
치환 후 $\int_0^1 \cos u\,du$
부정적분 $\sin u + C$
FTC $\big[\sin u\big]_0^1 = \sin 1 - \sin 0$
답 $\mathbf{\sin 1} \approx 0.841$

→ “안쪽 함수 $x^2$ + 그 미분 $2x$ 가 식에 마침 있어서” u-치환 통함. 가우시안 표준화와 똑같은 발상.

D. 비초등 — 가우시안 (대조)

D1. $\displaystyle\int_{-1}^{+1} \dfrac{1}{\sqrt{2\pi}} e^{-z^2/2}\,dz$

단계 식
부정적분 $\Phi(z)$ ← 비초등, 닫힌 식 없음
FTC $\big[\Phi(z)\big]_{-1}^{+1} = \Phi(+1) - \Phi(-1)$
다항 근사 $\Phi(+1) \approx 0.8413, \;\; \Phi(-1) \approx 0.1587$
답 $\mathbf{0.6827}$ (= 68.27%)

→ 추가로 근사 한 단계 더 필요. 이게 가우시안의 특수성.

2. 가우시안 분포

식

\[P(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)\]

where

  • $\mu$ (평균): 종의 중심 위치
  • $\sigma^2$ (분산): 종의 퍼짐 정도 (큼 → 넓고 낮음)
  • $\sigma$ (표준편차): 분산의 제곱근

종 모양

→ 중심 μ 에서 가장 높음, 양옆으로 갈수록 빠르게 (지수적으로) 낮아짐. ±σ 영역 (주황) 안에 약 68% 의 확률이 모여 있음.

μ, σ 의 역할

μ 변경 — 위치 이동

→ μ 가 종의 위치 — 모양은 같고 좌/우로 평행이동.

σ 변경 — 폭/높이

→ σ 작음 = 정밀 (좁고 높음), σ 큼 = 부정확 (넓고 낮음). 두 곡선 모두 면적 = 1.

“1σ, 2σ, 3σ” 직관

범위 그 안에 들어갈 확률
$\mu \pm \sigma$ 68%
$\mu \pm 2\sigma$ 95%
$\mu \pm 3\sigma$ 99.7%

→ “3σ 밖 은 거의 안 나옴” 직관.

표준정규 CDF — Φ(z)

CDF = Cumulative Distribution Function = 누적분포함수.

표준정규 CDF = 표준정규 분포 $\mathcal{N}(0, 1)$ 의 CDF, 기호 $\Phi(z)$.

정의

\[\Phi(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-t^2/2}\,dt = P(Z \le z)\]

→ “$-\infty$ 부터 $z$ 까지의 표준정규 PDF 누적 면적” = “$Z \le z$ 일 누적 확률”.

PDF 와 CDF — 시각적

→ PDF 아래 음영 면적 (왼쪽) 이 곧 CDF 의 z 시점 높이 (오른쪽). 같은 정보의 두 표현.

주요 값 (외워두면 편함)

$z$ $\Phi(z)$ 의미
$-\infty$ 0 완전 왼쪽
-3 0.0013  
-2 0.0228  
-1 0.1587  
0 0.5 평균 = 정확히 절반 (대칭)
+1 0.8413  
+2 0.9772  
+3 0.9987  
$+\infty$ 1 완전 오른쪽 = 전체

핵심 성질

  1. $0 \le \Phi(z) \le 1$ — 항상 확률 (0~1)
  2. 단조 증가 — $z$ 클수록 누적 큼. 절대 감소 X.
  3. 대칭성: $\Phi(-z) = 1 - \Phi(z)$. 예: $\Phi(-1) = 1 - 0.8413 = 0.1587$ ✓
  4. 미분 = PDF: $\Phi’(z) = \varphi(z)$ (FTC 직접 결과)
  5. 비초등 — 닫힌 식 없음, 다항 근사 (erf 변환) 로 계산

어디에 쓰나

  • 구간 확률 ★ — $P(z_a < Z < z_b) = \Phi(z_b) - \Phi(z_a)$. 우리 데모의 정체.
  • z-score 테이블 — 통계학 / 시험 / 품질관리 등 표준화 지표
  • 신뢰구간 — “95% 신뢰구간” = $\Phi^{-1}(0.975) \approx 1.96$
  • 가설 검정 — p-value 계산

일반 가우시안의 CDF 와의 관계

$X \sim \mathcal{N}(\mu, \sigma^2)$ 의 CDF $F_X(x)$:

\[F_X(x) = P(X \le x) = \Phi\left(\frac{x - \mu}{\sigma}\right)\]

→ 표준화 치환 후 $\Phi$ 호출. 이래서 $\Phi$ 표 한 장이면 모든 가우시안 처리 가능.

예 — 키 분포 ($\mu = 170, \sigma = 7$) 에서 “키 ≤ 177 일 확률”:

\[F_X(177) = \Phi\left(\frac{177 - 170}{7}\right) = \Phi(1) = 0.8413 = 84.13\%\]

데모 코드와의 매핑

function gaussianCDF(x) {
  return 0.5 * (1 + erf((x - MU) / (SIGMA * Math.SQRT2)));
  //     ↑                                  ↑
  //     Φ(z) = (1/2)[1 + erf(z/√2)]       z = (x − μ)/σ (표준화)
}

function intervalProb(a, b) {
  return gaussianCDF(b) - gaussianCDF(a);  // ← Φ(b) − Φ(a)
}

한 줄 ★

표준정규 CDF $\Phi(z)$ = “$Z \le z$ 일 누적 확률”. $\Phi(z) = \int_{-\infty}^z \varphi(t)\,dt$ — PDF 아래 누적 면적. $\Phi(0) = 0.5$, $\Phi(\pm\infty) = 0/1$, 단조 증가, S 모양. 비초등 → 다항 근사로 계산. 가우시안 구간 확률 = $\Phi(z_b) - \Phi(z_a)$ — 우리 적분의 핵심.

왜 가우시안이 흔한가

  1. 중심극한정리 (CLT) — 작은 무작위 효과를 더하면 가우시안에 수렴
  2. 수학적 편의 — 미분/적분/conjugate 등 모두 깔끔
  3. 자연 현상 — 키, 시험점수, 측정 노이즈 등 대부분 가우시안에 가까움

→ “모를 때 가우시안 가정 이 디폴트”.

한 줄

가우시안 = 평균 $\mu$ + 분산 $\sigma^2$ 의 종 모양. 자연 현상 + 수학 편의 → MLE/MAP 의 기본 분포.

3. 독립 + 곱셈 규칙

독립이란

“한 사건이 다른 사건에 영향 X”

예:

  • 동전 두 번 던지기 — 첫째 앞이든 뒤든 둘째 확률 변화 없음 → 독립
  • 카드 두 장 뽑기 (안 넣고) — 첫 장이 둘째에 영향 → 종속

독립 사건 곱셈 규칙

둘 다 일어날 확률 = 각 확률의 곱:

\[P(A \text{ AND } B) = P(A) \cdot P(B) \quad (\text{A, B 독립})\]

예 — 동전 두 번

사건 확률
첫째 앞 1/2
둘째 앞 1/2
둘 다 앞 1/2 × 1/2 = 1/4

왜 곱? — 나무 그림

         첫째 던짐                    
        /         \                   
   앞 (1/2)    뒤 (1/2)              
    /  \         /  \                 
  앞   뒤      앞   뒤                
 1/4  1/4    1/4   1/4               
   ↑                                   
   둘 다 앞                            
                                       
   각 가지 = 두 단계 곱셈

→ “가지 따라 가면서 곱하면” 그 잎의 확률.

N 개로 일반화

$N$ 개 독립 사건:

\[P(A_1 \text{ AND } A_2 \text{ AND } \ldots \text{ AND } A_N) = \prod_{i=1}^{N} P(A_i)\]

→ 곱 기호 $\prod$ 의 등장.

MLE/MAP 와 연결

데이터 $N$ 개가 독립일 때 likelihood:

\[L(w) = \prod_{i=1}^{N} p(y_i \mid w)\]

→ 각 점 PDF 값의 곱 (회귀처럼 $y$ 가 연속이면 엄밀히는 확률이 아닌 밀도. argmax 엔 무관).

log 하면 합으로:

\[\log L(w) = \sum_{i=1}^{N} \log P(y_i \mid w)\]

→ 이게 MLE 의 출발.

한 줄

독립 사건 둘 다 일어남 = 곱. $N$ 개 데이터 likelihood = $\prod P_i$, log → $\sum$.

4. 조건부 확률 P(A|B)

정의

\[P(A \mid B) = \text{"B 가 일어났을 때 A 의 확률"}\]

→ “B 알 때” — 조건부.

식

\[P(A \mid B) = \frac{P(A \text{ AND } B)}{P(B)}\]

→ “두 가지 동시 / B 자체” 비율.

직관 — 카드

카드 한 장 뽑기:

사건 확률
하트 13/52 = 1/4
빨강 (하트 + 다이아) 26/52 = 1/2
빨강일 때 하트일 확률 $P(\text{하트} \mid \text{빨강})$ = 13/26 = 1/2

계산: \(P(\text{하트} \mid \text{빨강}) = \frac{P(\text{하트 AND 빨강})}{P(\text{빨강})} = \frac{13/52}{26/52} = \frac{1}{2}\)

→ “빨강 안에서만 보면 절반이 하트”.

MLE/MAP 와 연결

표기 의미
$P(D \mid w)$ “$w$ 가 정해졌을 때 데이터 $D$ 가 나올 확률” — likelihood
$P(w \mid D)$ “$D$ 를 봤을 때 $w$ 의 분포” — posterior

→ 둘이 다른 확률 — 베이즈 정리로 연결.

한 줄

$P(A \mid B)$ = “B 일 때 A 의 확률” — 조건부. “B 가 우주를 좁힘”. $P(D \mid w)$ (likelihood) 와 $P(w \mid D)$ (posterior) 는 다른 확률.

5. 베이즈 정리

식

\[\boxed{P(w \mid D) = \frac{P(D \mid w) \cdot P(w)}{P(D)}}\]

where

  • $P(w \mid D)$: posterior (사후) — 데이터 본 후 $w$ 의 분포
  • $P(D \mid w)$: likelihood — $w$ 알 때 데이터 그럴듯함
  • $P(w)$: prior (사전) — 데이터 없을 때 $w$ 의 분포
  • $P(D)$: evidence — 데이터 자체의 확률 ($w$ 무관 상수)

유도

조인트 확률 두 가지 분해:

\[P(D, w) = P(D \mid w) \cdot P(w) = P(w \mid D) \cdot P(D)\]

양변 $P(D)$ 로 나누면:

\[P(w \mid D) = \frac{P(D \mid w) \cdot P(w)}{P(D)}\]

직관 — “사전 + 데이터 → 종합”

사전 정보 (P(w))     ×    데이터 적합 (P(D|w))                    
                                                            
"미리 알던 w"          "데이터가 그럴듯한 w"               
       ↓                       ↓                            
              곱                                            
              ↓                                             
   posterior (P(w|D))                                        
       ↓                                                    
   "둘 다 만족하는 w 가 진짜 답"

→ “미리 알던 정보 + 새 데이터 = 종합 추정”.

비유 — 키 추측

새 사람 키 추측:

정보 형태 결과
Prior $P(w)$ “한국 평균 170 ± 7 cm” 사전 분포
Likelihood $P(D \mid w)$ “측정 1번 = 168 cm (자 ±5cm)” 데이터
Posterior $P(w \mid D)$ “169 cm 정도” 두 정보 종합

→ 둘이 동의하는 위치 가 가장 그럴듯.

$P(D)$ 무시 가능 ★

MAP 풀이에서:

\[\arg\max_w P(w \mid D) = \arg\max_w \frac{P(D \mid w) P(w)}{P(D)}\]

$P(D)$ 는 $w$ 와 무관 (상수) → 정점 위치 안 바꿈:

\[= \arg\max_w \big[P(D \mid w) \cdot P(w)\big]\]

→ 자주 쓰는 표기:

\[P(w \mid D) \;\;\propto\;\; P(D \mid w) \cdot P(w)\]

(비례 기호.)

한 줄

베이즈 정리 = “사전 정보 + 새 데이터 → 사후 분포” 의 수학.

$P(w \mid D) \propto L(w) \cdot P(w)$

“둘 다 만족 (AND) → 곱**”.

종합 — MLE/MAP 와 연결

MLE 시점

1. 모델 가정: y = ŷ(w) + ε                          
2. 노이즈 가정: ε ~ N(0, σ²) — 가우시안              
3. 한 점 PDF: P(y|w) = (1/√...) exp(-r²/2σ²)        
4. N 점 likelihood (독립 → 곱):                     
   L(w) = ∏ P(y_i | w)                              
5. log (곱 → 합):                                    
   ℓ(w) = ∑ log P(y_i | w) = C − SSE/2σ²            
6. MLE = arg max ℓ = arg min SSE

→ PDF + 곱셈 규칙 + log + 가우시안 이 다 등장.

MAP 시점 (추가)

7. Prior 가정: P(w) = N(0, τ²)                       
8. Posterior (베이즈):                               
   P(w|D) ∝ L(w) · P(w)                             
9. log + 가우시안 → SSE + λ‖w‖²                    
10. MAP = arg min [SSE + λ‖w‖²]

→ 베이즈 + 조건부 확률 추가 등장.

한 표

우리가 본 것 사용 어디서
PDF 한 점 확률 정의 가우시안 식
가우시안 노이즈 + prior 가정 likelihood, prior
곱셈 규칙 N 점 likelihood $\prod P(y_i)$
조건부 확률 likelihood 자체 $P(D \mid w)$
베이즈 정리 posterior 정의 MAP

→ 모두 MLE/MAP 의 기본 도구.

한 줄 요약

확률 입문 5가지:

  1. PDF = 확률 밀도, 면적이 확률
  2. 가우시안 = 종 모양, $\mu$/$\sigma$ 두 숫자
  3. 독립 → 곱, log 하면 합
  4. 조건부 $P(A|B)$ = “B 일 때 A”
  5. 베이즈 = $P(w|D) \propto L \cdot P(w)$ (사전 + 데이터)

이 다섯 개로 MLE/MAP/Bayesian 전부 이해 가능.
