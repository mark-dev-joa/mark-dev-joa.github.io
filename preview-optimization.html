최적화란 무엇인가?

한 문장으로: 어떤 함수의 값을 최소(또는 최대)로 만드는 입력값을 찾는 것.

\[\min_{\mathbf{x}} f(\mathbf{x})\]

Gradient Descent (경사 하강법)

직관 — 눈 감고 산에서 내려오기

산꼭대기에 눈을 감고 서 있다고 상상해보세요. 가장 낮은 곳(골짜기)으로 내려가고 싶은데, 눈을 감았으니 발밑을 더듬어서 "지금 어느 방향이 가장 가파르게 내려가는지" 를 느끼고, 그 방향으로 한 발짝 내딛습니다.

수식

\[\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha \nabla f(\mathbf{x}_k)\]
  • \(\mathbf{x}_k\) : 현재 위치 (k번째 스텝)
  • \(\nabla f(\mathbf{x}_k)\) : Gradient — 함수값이 가장 빠르게 증가하는 방향
  • \(\alpha\) : 학습률(learning rate) — 한 발짝의 크기

시각화 — 학습률에 따른 수렴 비교

아래 3D 시각화에서 \(f(x,y) = x^2 + y^2\) 포물면 위에서 학습률 3가지를 비교합니다. 마우스로 드래그하여 회전할 수 있어요.

α=0.5 (적절)
α=0.1 (느림)
α=3.0 (발산)
최솟값 (0,0)

Newton Method (뉴턴 방법)

Gradient Descent와 뭐가 다른가?

Gradient Descent는 1차 미분만 봅니다. Newton은 2차 미분(Hessian)까지 봐서, 최저점이 대략 어디쯤인지 한 번에 추정합니다.

수식 유도 — 테일러 전개

함수 \(f(x)\)를 현재 위치 \(x_k\) 근처에서 2차 테일러 전개:

\[f(x) \approx f(x_k) + f'(x_k)(x - x_k) + \frac{1}{2}f''(x_k)(x - x_k)^2\]

미분해서 0으로 놓으면:

\[\boxed{x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)}}\]

다변수에서는:

\[\mathbf{x}_{k+1} = \mathbf{x}_k - \mathbf{H}^{-1} \nabla f(\mathbf{x}_k)\]

사용 정보1차 미분 (Gradient)1차 + 2차 미분 (Gradient + Hessian)
수렴 속도선형 수렴 (느림)이차 수렴 (매우 빠름)

SLAM에서의 최적화 — 에러와 자코비안

이 섹션은 ALIDA 블로그 내용을 참고하여 SLAM 관점에서 최적화를 정리합니다.

에러(Error)의 정의

\[e(\mathbf{x}) = z - \hat{z}(\mathbf{x})\]

MLE 기반 에러 함수 유도

에러가 정규분포를 따른다고 가정하면:

\[E(\mathbf{x}) = \sum_i e_i(\mathbf{x})^T \Omega_i \, e_i(\mathbf{x})\]

Gauss-Newton — Normal Equation 유도

테일러 1차 근사 → 전개 → 미분=0:

\[\boxed{H\Delta\mathbf{x} = -b} \quad \text{where } H = J^T\Omega J, \; b = e^T\Omega J\]

LM 확장

\[\text{(GN)} \; H\Delta\mathbf{x} = -b \quad \longrightarrow \quad \text{(LM)} \; (H + \lambda I)\Delta\mathbf{x} = -b\]

Gauss-Newton Method

핵심: Hessian을 Jacobian으로 근사

\[\mathbf{H} \approx J_r^T J_r\]

\[\boxed{w_{\text{new}} = w_{\text{old}} - (J_r^T J_r)^{-1} J_r^T \mathbf{r}}\]

Levenberg-Marquardt Method

\[\boxed{w_{\text{new}} = w_{\text{old}} - (J_r^T J_r + \mu \mathbf{I})^{-1} J_r^T \mathbf{r}}\]

μ의 역할 — GD와 GN 사이의 스위치

  • μ가 큰 경우: Gradient Descent처럼 동작 (보수적, 안정적)
  • μ가 작은 경우: Gauss-Newton처럼 동작 (공격적, 빠름)

딥러닝 옵티마이저

Momentum

\[\mathbf{v}_{k+1} = \beta \mathbf{v}_k + \nabla f(\mathbf{w}_k)\] \[\mathbf{w}_{k+1} = \mathbf{w}_k - \alpha \mathbf{v}_{k+1}\]

Adam

\[m_k = \beta_1 m_{k-1} + (1-\beta_1)\nabla f\] \[v_k = \beta_2 v_{k-1} + (1-\beta_2)(\nabla f)^2\] \[\boxed{\mathbf{w}_{k+1} = \mathbf{w}_k - \frac{\alpha}{\sqrt{\hat{v}_k} + \epsilon}\hat{m}_k}\]
